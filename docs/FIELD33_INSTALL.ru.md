# LocalPilot Field 33 · 0.7.37 · самостоятельный Android APK

**Отдельное приложение**, не обновление уже установленных копий:
- APK: `LocalPilot_Field33_0.7.37.apk`
- Android ID: `org.localpilot.android.field33dyn`
- Launcher: **LocalPilot Field 33**
- Android 11 и новее; подписан и установлен в Android-эмуляторе перед публикацией.
- Field32, Field31, Field30, Standalone, Preview и Dev не удаляются и не обновляются.
- Калибровку и игровые профили нужно выбрать заново. Держите включённой только **одну** службу LocalPilot Accessibility.

## Что вошло
1. **Из опубликованного Field32**: геометрическое распознавание шаров/пушки «Шипучки», восстановление поля после смены изображения; изменения из Field31 для полупрозрачных пустых клеток 2048, правильного TRACE_LINE в «Нащупай ход» и строго ограниченного прямого хода по 72%-частично читаемому полю.
2. **Новое исправление**: в «Нащупай ход» динамит распознаётся как защищённый объект по сочетанию *красного цилиндра и жёлтой искры*. Он никогда не считается обычной фишкой и не может входить в цепочку. На двух пользовательских кадрах геометрический критерий отличил пять шашек динамита от остальных игровых иконок; дополнительная локальная проверка малых сдвигов ROI не дала ложных совпадений в просмотренной выборке. Это не гарантия работы на других масштабах.
3. Всякая неизвестная клетка, череп, динамит и оверлей остаётся запретной для жеста. Android ACK считается только квитанцией, а не доказательством игрового прогресса.

## Принципиальные ограничения
- Только **прямые** цепочки, не изогнутые; при неизвестных клетках обмены и группы запрещены.
- «Гошан», «Карканоид», «Маркет Раш», «Прыгун Ари» и оставшиеся игры не объявлены исправленными. Результаты на живом Android требуют отдельных подтверждённых игровых сессий и отчётов.
- Новое имя пакета необходимо из-за тестовой подписи предыдущих сборок. **Не удаляйте старые приложения или их данные ради установки.**
- Полный APK, checksum SHA-256 и статус опубликованы в GitHub Release. Исходники в ZIP не требуются для установки.
