# LocalPilot GameLab: реальное Android-приложение для тестирования

Ветвь: `feat/ondevice-gamelab-companion-20261104`. Базовое приложение LocalPilot-Android 0.8.1 и отдельный пакет `org.localpilot.gamelab`.

## Единый рабочий процесс

```text
Реальное приложение или GameLab
  → реальное окно Android
  → Accessibility / MediaProjection screenshot
  → Vision V2 + игровые признаки
  → действующая / обучаемая политика
  → ActionGate / InputPermit / TTL / STOP
  → dispatchGesture
  → Android ACK
  → ОТДЕЛЬНЫЙ свежий кадр + предметная игровая проверка
  → обучение только при подтверждённом игровом результате
```

Объекты на Canvas сами по себе не являются подтверждением успеха. У GameLab отдельный packageName, чтобы не ослаблять запрет управления собственной Activity. Настоящие игры Яндекс Маркета проходят отдельную полевую приёмку по issue #69.

## Что реально реализовано

- **GameLab Android**: отдельный устанавливаемый APK; 10 управляемых касаниями упрощённых оригинальных игровых сцен, позволяющих тестировать настоящий стек Android. Эти сценарии являются обучающими симуляциями и не являются точными клонами Маркета.
- **NES / Famicom**: JSNES 2.1.0 (Apache-2.0), настоящий JavaScript CPU/PPU внутри Android WebView. Ядро загружается в APK из tarball с закреплённым SHA-512 на этапе сборки; сетевые запросы из WebView блокируются. Свой .nes картридж выбирается через Android SAF. Настоящий NROM homebrew содержит 6502 код, кнопки и видеокадры. CI должен проверить реальные пиксели и команды.
- **Денди**: тот же NES-совместимый JSNES, цикл 50 Гц; это лишь приближённый режим совместимости и **не** аппаратно точная эмуляция Dendy.
- **DOS**: проверка типа файла. DOSBox Pure пока **не** встроен; нельзя утверждать, что DOS-программы запускаются.
- **UI**: общий стиль/контракт `shared/HubContract.java`, отдельный лог и пометка источника результата, без автоматического предоставления разрешения на управление.
- **Верификация**: `GameLabContractVerify`, `GameLabRetroVerify`, `tests/jsnes_nes_smoke.cjs` на настоящем CPU/PPU, инструментальный Android API30/35/36 и `tools/gamelab_device_smoke.py` (Android-композитор + реальное касание + видимое изменение). Эти проверки обязательны до слияния.
- **Защита**: симулированное изменение или эмуляторный пиксель **никогда** не засчитывается как настоящий успех Маркета. `HubContract.countsForMarketAcceptance` требует реальный пакет Маркета, физическое устройство, ACK и предметный визуальный свидетель.

## Что не завершено

- Точная визуальная совместимость всех десяти игровых сцен GameLab с игровыми детекторами LocalPilot и подтверждённый прогон именно через PilotService.
- DOSBox Pure: лицензия, ядро, Android-рендерер, клавиатура/мышь, реальный запуск DOS программы и тесты.
- Аппаратная проверка на телефоне и планшете. Зелёные эмуляторы не заменяют поле.
- Проверяемый перенос опыта из GameLab в реально установленную игру. Сейчас модели `RealGameNeuralCritic` разделены по package + game slot + profile. Обучение в GameLab не считается обучением реальных игр и не может автоматически переписать их веса.

## Компоненты сохраняем

STOP, ActionGate, InputPermit, TTL, Fail-Closed, защищённые черепа и динамит в профильном `SWAP_MATCH3`, UNKNOWN, единственный исполнитель, windowFocus/ROI и визуальное подтверждение действия. Не пытаться решать проблему отсутствия реальных движений ослаблением проверок.

## Скачивание и запуск

В GitHub Actions две отдельные debug-сборки. Установить **обе** версии в Android. Открыть LocalPilot-Android → «GameLab · 10 игр / ретро», затем выбрать игру и соответствующую механику на панели LocalPilot. Для настоящего Market требуется отдельно открыть приложение Маркета и снова выбрать его окно. Смена игрового окна не переносит права ввода. Старый основной `0.8.1` сохранён в архивной ветке `archive/0.8.1-before-ondevice-gamelab-20261104`.
