Эта диагностика **не исправляет классификатор автоматически** и не требует исходный JPEG для GitHub CI. Файл остаётся у оператора. Цель: подтвердить RGB/HSV фоновой части и центрального пикселя проблемной клетки на исходном скриншоте.

- Имя: \`Screenshot_2026-10-30-14-32-00-613_ru.beru.android.jpg\`.
- Квадратная разметка: [54, 825]..[638, 1409], размер 584×584.
- Сетка 4×4, шаг 146 пикселей.
- R2C4: [492, 971]..[638, 1117]; центр (565, 1044).
- Внутренняя кольцевая проба: узлы x,y на сетке с шагом 4 в пределах 51 px от центра, только радиусы 22..48 px; 355 узлов. Кольцо **может включать цифру, отблеск, тень или переход анимации**. Центр не обязательно является пикселем текста.
- Проба не меняет палитру и запрещающие инварианты \`Color2048Reader\`. Для изменения классификатора нужны реальные значения и отрицательные контрпримеры.

## Запуск с исходным JPG

Windows PowerShell:

\`\`\`powershell
$env:LOCALPILOT_JPG_DIR="D:\path\to\your\jpg"
.\gradlew.bat localJpgReplay
\`\`\`

Linux:

\`\`\`bash
./gradlew localJpgReplay -Dlocalpilot.jpgDir=/absolute/path/to/jpg-folder
\`\`\`

Или непосредственно через Java 21:

\`\`\`bash
java -Djava.awt.headless=true -Dlocalpilot.jpgDir=/absolute/path/to/jpg-folder tests/LocalJpgVerify.java
\`\`\`

Первая строка вывода Java-программы начинается с \`DIAG_2048_CELL_R2C4\`. Затем выводятся семь отдельных точек. Если JPEG отсутствует или уменьшен, задача завершается **с ошибкой**, а не подставляет выдуманные RGB.

## CI без личных изображений

\`\`\`bash
java -Djava.awt.headless=true tests/LocalJpgVerify.java --self-test
\`\`\`

Синтетическая проверка подтверждает координаты, правильность кольцевого среднего и защиту от выхода за границы. Её RGB(189,174,193) взяты из **искусственно окрашенного тестового кадра**, а не получены чтением отсутствующего JPEG. Это **не** измерение реального скриншота.

Не передавать личный JPG в GitHub, не включать его в APK/source bundles. Точный текст \`DIAG_2048_CELL_R2C4\` можно использовать в отдельном обсуждении, если требуется уточнение \`Color2048Reader\`.
