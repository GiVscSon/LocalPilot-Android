# LocalPilot Android 0.7.18-dev / code34

LocalPilot может запускать визуальный профиль в выбранном стороннем приложении
или браузере. Проверка пакета Яндекс Маркета больше не ограничивает запуск.
Выбор окна, разрешение Android, свежесть кадров, проверка видимого ответа и STOP
продолжают действовать. Системные окна и домашний экран не являются игровыми целями.

## Как использовать

1. Откройте установленную игру или сайт с игрой. Для браузера в списке приложений
   нажмите «Все приложения»; либо откройте игру самостоятельно и выберите «Окно».
2. В меню «Игра» выберите профиль: Прыгун, Арканоид, Машина, Птенец или 2048.
   Для разных игр в одном браузере задайте разные имена через
   «Игра → Имя игры · отдельное обучение». Перед переходом к другой игре
   выберите её имя и профиль. Адрес сайта автоматически не определяется.
3. Нажмите «Старт» и подтвердите «Показать экран», если Android запрашивает захват.
   Для 2048 можно выделить сетку вручную. Для Прыгуна доступна калибровка цветов.

## Сохранённые модели

Ключ модели теперь включает пакет приложения, выбранное имя и тип контроллера.
Счётчик проигрышей и калибровка Прыгуна используют ту же область данных.
При запуске другой игры статические параметры Прыгуна сбрасываются до загрузки
её модели. Старые записи в arcade-learning-v1.log не удаляются. Прежняя модель
без ключа приложения доступна только основному профилю Яндекс Маркета; сторонние
игры её не наследуют. Имена игр хранятся локально и не передаются в сеть.

## Границы поддержки

Открытие окна другой игры не добавляет универсального распознавания.
Арканоид, Машина и Птенец пока используют существующие геометрические и цветовые
шаблоны. Другие оформления могут требовать нового распознавателя. Для Прыгуна
можно изменить три опорных цвета, но механика должна соответствовать платформеру
с управлением касаниями слева/справа. Датчик наклона не эмулируется.
Детектор Game Over пока ориентирован на белую карточку с широкой жёлтой кнопкой.
Автоматический рост качества в любой неизвестной игре не гарантирован.
Web-режим внутри LocalPilot остаётся отдельным способом записи игр на сайтах.

## Проверки

tests/ResultVerify.java проверяет разрешённые внешние приложения и браузеры,
отбраковку системных окон, независимость приложений/имён/контроллеров,
сохранение после перезапуска, совместимость старой модели Маркета и сброс
параметров Прыгуна между играми. tests/Verify.java проверяет существующие
распознаватели, политику и ограничения ввода.
В облачной среде не подключено физическое устройство с этими сторонними играми.
