# Задание итерации 0.7.31-dev

Продолжить LocalPilot Android от проверенной 0.7.30, сохраняя Dev-пакет,
сертификат, пользовательские данные и отрицательные проверки.

1. Принять присланный справочник десяти игр как материал для адаптеров.
   Отделить подтверждённые правила от гипотез жанра и противоречий:
   осьминог6×6 меняет соседей по прямому уточнению пользователя;
   экранная осьY направлена вниз; 2048 не имеет гарантированной победы.
2. Расширить обычную Шипучку одним рикошетом: ограниченный перебор углов,
   первая коллизия, отражение только горизонтальной скорости, однозначное
   прикрепление, кластер и отсоединение от потолка. Не угадывать специальные
   шары, запасной снаряд, скрытые клетки или два рикошета.
3. Разделить координаты жеста и окончательного попадания. Не менять
   ActionGate/GestureFlight и не считать ACK попаданием.
4. Проверить путь независимым пошаговым оракулом; добавить левый/правый
   рикошет в трёх масштабах и отрицательные сценарии геометрии/свежести.
   Расширить Android-приёмку отдельной независимой целью в test APK:
   настоящий жест → видимые изменения → проверенное поле → STOP.
5. Прогнать JVM, build/lint, Android CI; собрать code47 прежним ключом,
   сохранить исходники и точку продолжения с честными границами проверки.

Границы: это развитие одного адаптера, а не объявление всех десяти игр
готовыми по текстовому описанию. Награды акций, ежедневные счётчики и время
их выполнения не подтверждаются синтетическим тестом.
