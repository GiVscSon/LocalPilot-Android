## Оставшиеся ограничения

- Автоигра только для встроенной профилированной тестовой NES-ROM. Это настоящее
  исполнение6502/PPU, но не универсальный игрок в произвольные коммерческие ROM.
  Импортированные ROM поддерживают ручное управление и сохранение/загрузку.
- До256 действий за явный сеанс, checkpoint каждые16; неполная серия при аварии
  может потеряться. Один слот; RNG политики не сохраняется.
- RAM-журнал вмещает256 записей суммарно, replay64серии. Старый опыт уменьшает
  доступный бюджет. При заполнении агент останавливается; bulk-export/ротация
  ещё не подключены. Не обещать бесконечную автоигру.
- PPO действительно меняет веса кандидата, но ожидающий экзамена кандидат
  сохраняется. Независимый экзамен нового кандидата, улучшение и автоматическое
  продвижение не завершены. Активные веса не подменяются.
- GGUF-путь пока4хода; веса загружаются отдельно, универсальной GGUF-тренировки нет.
- Реальные10 внешних игр, POCO/физический планшет, GPU/Vulkan runtime NOT_RUN.
  Нельзя считать четыре подсистемы полностью готовыми для любых игр.
