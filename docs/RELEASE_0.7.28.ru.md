# LocalPilot Android 0.7.28-dev / code44

## Недоступные границы окна

Пустые границы прежнего целевого окна теперь означают WINDOW_STATE_UNAVAILABLE,
а не TARGET_BOUNDS_CHANGED. Сеанс приостанавливает ввод до 600 мс и ждёт
точное прежнее окно. Непустые изменённые границы, другой ID и блокировка
сохраняют STOP. Старый ticket не становится пригодным после восстановления.
ActionGate.consume по-прежнему отвергает нулевые/отрицательные размеры;
новая классификация относится только к наблюдению состояния окна.

## Нативная проверка восстановления

Во время настоящего MediaProjection-сеанса на изолированном эмуляторе тест
инъецирует уведомление WINDOW_STATE_UNAVAILABLE. Затем реальный обработчик
службы и таймер проверяют прежнее окно, сохранение captureSession, отзыв
предыдущего ticket, отсутствие ввода в нераспознанную сцену и свежий кадр
после восстановления. Повторная потеря уведомляется перед настоящим нажатием
STOP; отложенная проверка не должна перезапускать захват. Поворот и остальные
сценарии предыдущей версии сохранены.

Это инъекция уведомления, не физический баннер Game Turbo. Матрица эмуляторов
не доказывает восстановление после конкретного системного диалога Xiaomi,
качество игры или устранение всех причин закрытия процесса.

Пакет org.localpilot.android.dev, прежний Dev-сертификат и данные сохранены.
Итог приёмки и хэши: VALIDATION_0.7.28.txt. Новые игровые профили не добавлены.

## Отложенное чтение после паузы

При паузе аннулируются задачи чтения сетки, повторного поиска поля и подготовки
2048, созданные до потери фокуса. После восстановления действует только новый
цикл: старый таймер не может запустить второй захват и вызвать CAPTURE_INFLIGHT.
Проверка включает инъекцию потери фокуса между настоящими ходами встроенной
2048, сохранение epoch и последующие визуально подтверждённые свайпы.
Реальные переходы между раундами сторонних игр этим тестом не подтверждены.

Итог: финальный a358a62 прошёл сборочный CI/JVM и все 13 нативных сценариев
на каждой из API30/35/36 (run40157528764). Подпись проверена, данные не
мигрируются и не удаляются. Установка поверх прежней Dev-версии.
