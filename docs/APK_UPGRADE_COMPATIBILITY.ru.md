# Проверка совместимости обновления APK LocalPilot

Цель: не заставлять пользователя удалять старую версию LocalPilot из-за
несовпадения пакета, сертификата или отката versionCode. Команда **ничего не
устанавливает**, не открывает ADB и не удаляет данные.

## Почему обычная подпись недостаточна

apksigner verify подтверждает, что **конкретный** APK подписан корректно.
Он не подтверждает, что установленная ранее версия использовала тот же ключ.
GitHub-hosted debug сборки могут использовать временные сертификаты, поэтому
**зелёный CI и новый APK не означают установку поверх предыдущего**.

Для постоянных обновлений нужен стабильный отдельный ключ подписания,
хранимый исключительно в защищённом хранилище CI или локально у издателя.
Нельзя публиковать JKS, пароли или private key в GitHub.

## Сравнение двух файлов без Android-устройства

Windows PowerShell или Linux, Python 3.10+ и Android SDK Build Tools 35:

    python scripts/localpilot.py upgrade-preflight --previous path/to/old.apk --candidate path/to/new.apk --sdk path/to/android-sdk --output upgrade-report.json

Или напрямую:

    python tools/apk_upgrade_preflight.py --previous path/to/old.apk --candidate path/to/new.apk

Проверка использует aapt dump badging и apksigner verify для **обоих**
файлов, а также CRC ZIP. Скрипт отклоняет:

- разный applicationId (старую установку нельзя обновить другим пакетом);
- разный SHA-256 подписывающего сертификата;
- не увеличенный versionCode (включая старую версию с тем же номером);
- полностью идентичный файл;
- повышение minSdk, которое отрежет поддерживаемые ранее устройства;
- повреждённые, неподписанные или многократно подписанные APK.

Команда возвращает 0 только для совместимого локального обновления,
1 при несовместимости и 2 при невозможности проверить файл или подпись.
Во всех случаях **ничего не устанавливается**.

## Критерии для публичного выпуска

- Проверить новый APK против **реально установленного предыдущего APK**,
  а не против случайного файла с таким же названием.
- Держать сертификат для следующих версий неизменным и повышать versionCode.
- Отдельно проверить установку и обновление на телефоне и планшете,
  сохранение настроек/моделей, функцию STOP и отказ в небезопасном вводе.
- Использовать существующие 20 проверок ZIP/исходников, матрицу Android и
  реальную полевую приёмку десяти игр.

compatible_update=true **не равно** release_ready=true: инструмент
проверяет только возможность обновления **двух локальных APK**, не фактическую
установку, устройство, функции или игровые результаты.


## Защищённый QA-кандидат с постоянной подписью

Добавлен **ручной** workflow GitHub Actions: Signed LocalPilot QA candidate.
Он запускается **только из проверенной main**, с точным 40-значным SHA
и защищённым окружением android-release (желательно с одобрением владельца).
В автоматический публичный выпуск он не превращается.

Настройки окружения GitHub Actions, которые владелец проекта устанавливает
самостоятельно:

- Secrets: LOCALPILOT_RELEASE_KEYSTORE_B64 (base64 keystore, НЕ открытый ключ),
  LOCALPILOT_RELEASE_STORE_PASSWORD, LOCALPILOT_RELEASE_KEY_ALIAS,
  LOCALPILOT_RELEASE_KEY_PASSWORD.
- Environment variable: LOCALPILOT_RELEASE_CERT_SHA256 (64 hex символа
  SHA-256 сертификата этого же постоянного ключа).

Никогда не записывать пароли, private key или JKS в исходный код, файлы
артефактов, сообщения чата и публичные CI-логи. Хранить защищённую
резервную копию ключа. Потеря ключа может навсегда исключить возможность
обновления приложения с прежним applicationId.

Workflow проверяет исходный SHA, наличие конфиденциальных параметров,
модели, исходные контракты, создает app-release.apk, выполняет двадцать
проверок и требует совпадения сертификата. Его результат **всегда QA-only**:
для публичной стабильной версии нужно независимо закрыть испытания
на настоящих телефонах и планшетах (issue #69).

Предыдущие Dev/APK, подписанные случайными debug-ключами, не становятся
обновляемыми поверх себя от появления нового постоянного сертификата.
В частности, debug package с суффиксом .dev.install1081 и стабильный
package без суффикса являются разными приложениями Android. Для уже
установленного пакета нельзя переключить сертификат через обычный
install -r; существующие данные нельзя молча очищать.
