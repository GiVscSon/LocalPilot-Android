# 0.7.9 — повторные раунды и запуск Карканоида

Основание: пользовательские скриншоты 2026-10-22. ARI: READ13/input1/ACK1, NO_CONTROL_RESPONSE; это подтверждает завершённый Android-жест, но не движение. PADDLE: READ121/решения93/input0, tracked=true/vx=vy=0, шар касается корзины. TRAFFIC: ROI224×718 при портретном окне2136×3200, экран результата останавливает всю сессию. Отдельно есть TARGET_WINDOW_UNAVAILABLE и ошибка стандартного поиска поля для цветной2048.

Изменения:
- PADDLE: если отслеживаемый шар неподвижен и касается корзины, отправляется запуск. Успех подтверждается перемещением шара; неподвижный ACK успехом не считается.
- TRAFFIC/FLAPPY: распознанный экран результата сбрасывает историю действий/слежения, но сохраняет MediaProjection, привязку и ROI. Пользователь нажимает «Играть снова» в игре; после двух пригодных кадров управление продолжается. Автоматического нажатия рекламы/кнопок результатов нет. STOP, блокировка и действительная смена окна по-прежнему прекращают сессию.
- Портретное окно приложения больше не обрезается поиском боковых полос: обочины дороги не принимаются за внешние поля. Ручная область сохраняет приоритет. Для широкого окна автопоиск полос остаётся.
- Распознавание копирует Bitmap одним getPixels и читает Java-массив; убраны многократные JNI getPixel в обработке каждого пикселя. Фактический выигрыш задержки на устройстве пока не измерен.

Не исправлено/не доказано: причина отсутствия движения Ари; универсальное распознавание цветной2048; временная недоступность Accessibility-окна. Профили и захват сохраняются между результатом и новым раундом только пока исходное окно остаётся доступным. Не обещать полный автоматический повтор всех игр.

Проверка: JVM-регрессии включают запуск шара из координат пользовательского отчёта, отклонение неподвижного ответа, подтверждение движения и запрет запуска для далёкого шара. Android instrumentation только компилируется; физического телефона нет. После установки выбрать окно и профиль один раз, затем Старт/разрешение захвата. После Game Over нажать повтор в самой игре — для TRAFFIC/FLAPPY не нужно заново настраивать LocalPilot, если окно не сменилось.
