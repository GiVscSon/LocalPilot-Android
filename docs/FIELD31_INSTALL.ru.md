# LocalPilot Field 31 · экспериментальная версия 0.7.35 (30 октября 2026)

## Отдельная установка без конфликта

- APK: **LocalPilot_Field31_0.7.35.apk** (полный установочный файл, не ZIP)
- Android package: **org.localpilot.android.field31**
- Launcher: **LocalPilot Field 31**
- Отдельное хранилище, настройки, калибровка и служба специальных возможностей.
- Не обновляет и не удаляет Field 30, Standalone, Preview или Dev. **Прежние данные не удалять**.
- Перед включением новой службы выключите AccessibilityService старой копии, чтобы два пилота не отправляли жесты одновременно.

## Что исправлено на основании кадров реального телефона

1. **Цветной 2048:** расширена безопасная классификация пустых полупрозрачных клеток. Зафиксированы RGB реальной сцены и 16 синтетических проверок. Цветные неизвестные плитки по-прежнему вызывают безопасное ожидание.
2. **«Нащупай ход»:** профиль 11 теперь использует TRACE_LINE вместо неправильного SWAP_MATCH3; черепа остаются непроходимыми. Старое поле и палитра SWAP не импортируются: выделите ROI заново.
3. **Фишки и цепочки:** после двух устойчивых кадров допускается ТОЛЬКО прямая линия через распознанные обычные фишки при известности минимум 72% клеток. Неизвестные, черепа и бустеры нельзя пересекать. Частичные SWAP/GROUP и изогнутые линии пока не посылаются.
4. Android ACK сам по себе не засчитывается за успешный ход: требуется подтверждённое изменение игрового поля.

## Границы приёмки

Это **тестовая сборка**, а не утверждение, что все десять мини-игр работают. Реальные видеозаписи и скриншоты раскрыли проблемы FLAPPY (много ACK при нулевом счёте), слабый результат Arkanoid, пропуски кадров и неизвестные особые клетки. Изогнутые восьмисоседние цепочки для «Нащупай ход» пока не отправляются. Игра в реальном приложении на новой версии ещё не проверена.

Публикация выполняется только после проверки APK/подписи/пакета и установки с запуском в Android-эмуляторе. Для физического теста откройте LocalPilot Field 31, включите только его службу, выберите окно Маркета, нужный профиль, обведите ROI, затем запустите. При повторном сбое экспортируйте «Отчёт с кадром игры».

**Важно:** независимая CI-подпись данной экспериментальной сборки не гарантирует обновления будущим APK с тем же package. Для нового независимого выпуска используется новый уникальный ID, а не удаление старого приложения и данных.
