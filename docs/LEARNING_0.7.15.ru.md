# Автообучение 0.7.15-dev

Во время автоматической игры обучение включено постоянно. После каждого действия, подтверждённого новым кадром игры, модель сохраняется в закрытом хранилище приложения. При новом запуске службы она загружается до первого решения и продолжает обновляться.

Для Прыгуна Ари сохраняются отдельные параметры выбора платформ: допуск выравнивания и дальность достижимости. Успешное подтверждённое движение постепенно расширяет достижимость, отсутствие движения делает выбор осторожнее. Для птенца, Машины и Карканоида сохраняются физические параметры контроллера. Неудачные и неподтверждённые действия не считаются успешными.
