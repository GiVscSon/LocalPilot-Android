# LocalPilot Android 0.7.22-dev / code38

Исправления по сообщению пользователя: в браузере открыты пузырьки, но панель
продолжает искать «Маркет Раш»; также LocalPilot закрывается/теряет панель.
Точный источник закрытия без нового журнала падения не установлен.

## Выбор механики вместо старого глобального профиля

- Выбор сохраняется отдельно для приложения и имени игры. Глобальный последний
  профиль больше не является основанием автоматически начать новую игру.
- Перед новым браузерным сеансом нужно подтвердить механику через «Игра».
  URL не собирается, сайт не угадывается по картинке. Подтверждение относится
  к текущему приложению и имени игры, а не переносится из другого окна.
- При событии Android о смене состояния браузерного окна после распознавания
  игры ввод останавливается. Это не детектор всех переходов внутри canvas:
  перед ручной сменой игры используйте STOP и заново подтвердите механику.
- После обновления первый Старт в приложении может открыть выбор механики.
  Выберите тип, затем нажмите Старт. Для разных игр в одном браузере используйте
  разные имена через «Игра → Имя игры · отдельное обучение».
- Названия аркад теперь описывают механику: платформенный прыгун, платформа/шар,
  трёхполосная машина, птица с пролётом. Это не означает распознавание произвольной
  графики: для другого оформления нужна «Ещё → Настроить распознавание».
- Добавлен явный пункт «Пузырьки / другой неподдержанный тип». Он не запускает
  контроллер машины. Решатель пузырьков пока не реализован.
- Если сцена остаётся неизвестной шесть секунд, захват и ввод останавливаются
  с предложением выбрать механику/область/калибровку. Бесконечный поиск старого
  профиля больше не продолжается. Первый найденный кадр получает возможность
  подтверждения следующим; два свежих пригодных кадра по-прежнему обязательны.

## Нагрузка и обработка ошибок

- Служба не декодирует и не создаёт следующий Bitmap, пока анализатор занят
  или кадр уже ожидает обработки. Native Image при пропуске закрывается.
- Минимальный интервал кадров увеличен с 60 до 80 мс (максимум 12,5 кадров/с).
- Полная копия пикселей зеркального кадра переиспользуется одним visionWorker;
  ёмкость ограничена 480×720 пикселями. После изменения размера читается только
  действительная область текущего кадра.
- CustomArcadeVision переиспользует RGB, маски, очередь обхода и visited-массивы
  в ограниченном ThreadLocal. Результирующие списки и объекты продолжают выделяться;
  полного Zero-GC не заявляется. Проверены уменьшение/увеличение размеров и пустой
  кадр после заполненного: старые пиксели не становятся новыми объектами.
- Ошибки RuntimeException/OutOfMemoryError при подготовке кадра на главном потоке
  обрабатываются остановкой захвата; тип ошибки остаётся локальной фазой диагностики.
  Это не гарантирует защиту от системного low-memory kill или native crash.

## Проверка на телефоне

Физического Android-теста здесь нет. Для приёмки: открыть браузер, выбрать окно,
Старт → нужную механику → Старт; проверить смену игры и работу STOP.
На неподдержанной игре не должно быть жестов или бесконечного поиска машины.
Если снова исчезает панель, открыть LocalPilot и явно экспортировать локальную
диагностику/отчёт падения. По нему различить Java crash, native crash, ANR
и завершение процесса Android из-за памяти. Отправка остаётся действием пользователя.
