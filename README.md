## Основная линия разработки: LocalPilot-Android 0.8.1

Продолжение 10.11.2026: [единый APK и проверяемая интеграция](docs/UNIFIED_INTEGRATION_2026-11-10.ru.md), [PR #90](https://github.com/GiVscSon/LocalPilot-Android/pull/90). В него переносятся совместимые изменения NES Agent Lab (#91), ручных учебных аркад (#92) и правил GameLab (#93). Это кандидат; физическая приёмка десяти игр не выполнена. Последний проверенный SHA и APK указаны в PR и встроены в приложение.

**Основная ветка:** `main`. Новые движки являются основным направлением разработки, а не отдельным постоянным экспериментальным ответвлением:
- **Vision V2** (PR #79): сырой временной поток кадров и фильтрация ROI перед распознаванием игровых объектов.
- **RealGameNeuralCritic** (PR #80): обучаемая по визуально подтверждённой обратной связи нейросеть для PADDLE/TRAFFIC/FLAPPY, встроенная в основной контроллер. Она может консервативно отклонять неподтверждённые действия, но не обладает дополнительными правами на ввод.
- **GameLab**: в объединённом кандидате встроен в основной APK вместе с NES. Отдельное приложение нужно только для специальных межпроцессных Android-тестов. Диагностические игровые сцены и собственные учебные аркады не доказывают прохождение настоящих игр Маркета.
- **Проверка внешней 2048 через PilotService** (PR #82): на момент 5 ноября 2026 года остаётся draft с упавшей матрицей Android API30/35/36, не включена в `main`.

**Статус:** основная *ветка разработки*, **не подтверждённый стабильный релиз**. Открытая [задача #69](https://github.com/GiVscSon/LocalPilot-Android/issues/69) блокирует заявление о полной работе десяти игр до подтверждённых ходов и визуальной приёмки на телефоне и планшете.

**Откат:** исходная 0.7.34 сохранена в `backup/v0.7.34-before-weightspace-20261104`, основная 0.7.35 до Vision V2 в `archive/localpilot-android-0.7.35-before-vision-v2-20261104`. Не переписывать резервные ссылки. Новый debug APK `0.8.1-dev-install1081` ставится параллельно прежнему. Защиты STOP, ActionGate, InputPermit, TTL, UNKNOWN, проверка окна и визуальное подтверждение после жеста обязательны.

## Запуск игры — три шага

При первом запуске включите службу кнопкой «Включить управление» и покажите панель.

1. Откройте игру.
2. На панели LocalPilot выберите название игры.
3. Подтвердите «Показать экран» и начните раунд.

STOP прекращает управление. Системное подтверждение захвата Android обязательно. Если приложение закрывается, откройте его снова и нажмите «Экспорт диагностики сбоя».

Web-игры открываются отдельно через «Web · варианты обучения». Три режима и ограничения: [Web-обучение](docs/WEB_LEARNING.ru.md).

0.6.4: ограничен размер кадров захвата (до720×480), буфер используется повторно, координаты переводятся обратно в экран телефона. Добавлен «Экспорт диагностики сбоя» без необходимости включать службу. Причина пользовательского вылета пока не установлена; проверка на устройстве обязательна.

0.6.3: поздний ответ Android о завершении жеста не отклоняется только из-за истечения TTL отправки. Проверки приложения/окна/STOP сохранены. Демо обновляет координаты цели и проверяет прирост счёта после каждого тапа. Оно остаётся на 10 касаний, временной бюджет — 60 секунд; экспорт задержек сохраняет LAST_STOP. Проверка на телефоне требуется.

0.6.2: на Android14+ запрашивается весь экран через официальный MediaProjectionConfig; системное подтверждение остаётся. В развёрнутой панели и экспорте видны счётчики кадров, READ, решений, отправленного ввода и ACK. Ошибка этапа разворачивает панель. Реальная игра требует проверки на устройстве.

В 0.6.1 исправлена гонка первого кадра и добавлена диагностика остановки после выбора экрана Android. Панель показывает этапы 1–5; таймеры завершают зависшую попытку с ошибкой. Порядок проверки: [запуск захвата](docs/CAPTURE_STARTUP.ru.md). Работа на физическом устройстве ещё не подтверждена.

Нативное приложение для Android11+. Новая версия добавляет **четыре собственных аркадных симулятора и обучение Double DQN на телефоне**. Отдельно сохраняется управление встроенными2048, крестиками-ноликами и Lights Out через Accessibility.

## Обучение на Android

Откройте «Аркады · обучать нейросеть», выберите жанр и нажмите «Обучать». Доступны вертикальный джампер, вертикальный платформер, раннер по полосам и Jetpack. Компактная сеть получает64 признака объектов, обучение работает на CPU без Python, сервера, GPU и обращения к сети (web-режимы используют отдельные сетевые функции).

«Пауза / STOP» сохраняет checkpoint, повторное «Обучать» продолжает его. Уход приложения в фон ставит обучение на паузу. «Показать модель» демонстрирует замороженную политику; «Оценить ×50» сравнивает её со случайной стратегией, не меняя веса. Отчёт прямо сообщает, подтверждено ли преимущество. Сохранение весов не означает успешного освоения игры.

Checkpoint включает optimizer, replay, RNG и физическое состояние; SHA256 и конфигурация проверяются при загрузке. Предыдущая копия сохраняется, повреждённый основной файл не заменяет исправный backup. Экспорт доступен через системный выбор ZIP-файла после паузы.

Обучение проходит в наших симуляторах. Скриншотная политика для сторонних игр работает отдельно и не использует эти DQN checkpoint.

Полные механики, действия, награды, гиперпараметры, формат и перенос на ПК: [training/README.ru.md](training/README.ru.md).

## Управление установленными играми

Автоуправление включено по умолчанию, настройка сохраняется. После выбора игры LocalPilot ждёт устойчивое окно, сворачивает панель и ищет поддерживаемое поле. Встроенные2048/TTT/Lights используют реальные Accessibility-границы, внешняя2048 — строгую стандартную палитру. Для наблюдавшейся цветной сетки есть экспериментальный режим: пользователь вручную выделяет квадрат4×4, распознаватель принимает только увиденные на записи значения2/4/8/16 и останавливается на неизвестном цвете. Это не OCR и не подтверждено на телефоне. Другие игры автоматически не управляются.

Чтобы запустить цветной 2048: откройте игру → «Привязать» → «Выбрать поле» и обведите только сетку 4×4 → «Цветной 2048». Пока на записи видны только значения2/4/8/16. При неизвестном цвете, анимации или плитке выше16 автоматический ввод остановится; обычный «Авто2048» использует стандартную палитру.

Повторных диалогов разрешения в обычном авторежиме нет. После стабильного распознавания начинается игра без прежних лимитов20/40 действий и60/120 секунд, до STOP, конца партии, ошибки или смены окна. «Демо ×10» остаётся отдельным ограниченным диагностическим тестом. «Только чтение» выключает автоуправление; явная кнопка ввода включает его.

Компактная панель160×48dp имеет фон55% непрозрачности, видимые STOP и «Развернуть». Она пытается переместиться вне поля; прозрачность не отменяет запрет перекрытия распознавания и жестов. Разворачивание возвращает обычный фон. STOP отзывает текущую сессию, без автоматического возобновления при возврате в игру.

Проверки пакета/окна/геометрии, свежести кадра, одноразового ticket и результата каждого хода сохранены. Уже отправленный жест может завершиться после STOP. Системную службу Accessibility пользователь включает средствами Android.

## Карканоид, Маркет Раш и Гошан

В панели добавлены три экспериментальных зрительных профиля. В «Карканоиде» LocalPilot отслеживает красный шар и корзину, оценивает точку приземления с отражением от стен и перетаскивает платформу. В «Маркет Раш» он определяет дорогу, фургон и машины, затем касается левой или правой половины экрана для перехода на свободную соседнюю полосу. В «Гошан, вперёд!» он ищет персонажа и проход между стопками еды, касанием поднимая персонажа к проходу.

1. Откройте нужную мини-игру в Яндекс Маркете и запустите раунд.
2. Нажмите кнопку с названием игры на панели: отдельная привязка не нужна.
3. Подтвердите системный захват экрана Android. Поле определяется автоматически, панель сворачивается; для «Гошана» она размещается ниже игровой области.
4. Нажмите STOP для завершения. «Диагностика» также останавливает ввод и показывает координаты и число подтверждённых реакций.

Каждое касание требует видимого ответа: сдвига корзины, фургона или изменения вертикального движения персонажа. При потере объектов включается автоматический повторный поиск. Зависший захват, отсутствие реакции после восстановления видимости, смена окна или распознанный экран результата останавливают управление. Реклама и кнопки повторной игры автоматически не нажимаются. Профиль нужно запустить заново после начала следующего раунда.

Эти профили проверены на синтетических сценах и298 кадрах трёх пользовательских видео; автоматическая игра на телефоне ещё не проверена. Изменение оформления или правил может потребовать доработки. Веса DQN из собственных симуляторов в этих профилях не используются. Подробности и границы проверки: [docs/ARCADE_PROFILES.ru.md](docs/ARCADE_PROFILES.ru.md).

## Прыгун Ари в Яндекс Маркете

Откройте мини-игру в Яндекс Маркете, оставьте её на экране и нажмите на панели LocalPilot «Прыгун Ари». Android запросит доступ к захвату экрана для каждой сессии и покажет постоянное уведомление с STOP. Поток кадров работает локально в памяти.

Распознаватель ищет жёлтого персонажа, оранжевые платформы и красные шипы по цвету и форме, отслеживает движение и выбирает безопасную ближайшую платформу. Автопилот касается левой или правой зоны и ждёт кадр, подтверждающий изменение положения. Если сцена не распознана, разверните панель, нажмите «Калибровка Ари» и отметьте персонажа, платформу и шип на стоп-кадре. Цветовые образцы сохраняются локально. Автоматической записи экрана нет. Один последний кадр игры остаётся в RAM для явного экспорта «Отчёт с кадром игры».

При потере сцены распознавание повторяется автоматически. При смене окна или отсутствии ответа на касание ввод останавливается. STOP доступен на компактной панели и в уведомлении Android. Профиль рассчитан только на «Прыгуна Ари»; он не управляет колесом промокодов, рекламой и навигацией Маркета.

Это первая зрительная стратегия, а не проверенная на телефоне модель. На устройстве ещё нужно подтвердить захват MediaProjection, обнаружение объектов и реакцию игры на касания. При облачной сборке подключённого Android нет.

Журнал теперь ротируется: восемь сегментов до512КиБ, отдельные checksum-цепочки, экспорт ZIP. Старый audit-v1.log сохраняется без изменения и копируется отдельно. При заполнении256 примеров сбор выключается, игра продолжается; реальные ошибки записи по-прежнему останавливают ввод.

## Установка

Dev APK имеет пакет **org.localpilot.android.dev**. Текущая версия задаётся только
в app/build.gradle; фактические версия и сертификат проверяются перед упаковкой.
Обновление сохраняет данные при совпадении ключа и устанавливается рядом
с оригинальным org.localpilot.android. Оригинал удалять не требуется.

1. Установить Dev APK.
2. Для обучения открыть «Аркады» — Accessibility не требуется.
3. Для внешнего управления включить именно Dev Accessibility-службу и выбрать поддерживаемую игру.
4. Для «Прыгуна Ари» открыть мини-игру до привязки; при первом запуске подтвердить экранный захват Android. Для паузы использовать STOP; после остановки запустить режим явно заново.

## Сборка и проверки

Нужны JDK17/21, SDK Platform35 и build-tools35.0.0:

```bash
java tests/Verify.java tests/legacy_parity.txt
java tests/RlVerify.java
./gradlew --no-daemon :app:assembleDebug :app:lintDebug :app:assembleDebugAndroidTest
python3 tools/package_release.py
```

В Windows использовать gradlew.bat. APK: app/build/outputs/apk/debug/app-debug.apk.
`python3 build_debug.py` запускает ту же Gradle-сборку и проверяет версию, пакет
и подпись APK. Отдельная ручная сборка с другим ключом больше не используется.
`python3 tools/package_release.py` берёт версию из app/build.gradle, проверяет
готовый APK и создаёт новую папку release/LocalPilot_Android_<версия>_dev
с APK, исходниками, MANIFEST.json, SHA256SUMS и ZIP-комплектом.
Существующая папка выпуска не перезаписывается. Для контрольной упаковки используйте
`--output /другая/папка`; для проверки ключа — `--expected-certificate SHA256`.
Локальные ключи, записи экрана, журналы устройства и обучающие данные не включаются.
Проверка известных шаблонов секретов не заменяет проверку исходников перед публикацией.
Регрессии инструментов: `python3 -m unittest discover -s tests -p test_release_tools.py -v`.
GitHub Actions не получает локальный ключ: сертификат CI APK может отличаться
от установленного приложения. Для обновления на телефоне проверяйте совпадение
сертификата; не удаляйте приложение ради обхода конфликта подписей.

Gymnasium-обёртки используют тот же Java-движок через JPype. Их можно применять позже на ПК; они не нужны Android-приложению. Инструкции и проверенные Python-версии находятся в training/.

Фактические результаты и ограничения — VALIDATION.txt, точка продолжения — LOCALPILOT_ANDROID_HANDOFF.md. Android-инструментальные тесты компилируются; выполнение на физическом устройстве здесь не подтверждено. Не считать сборку или JVM-проверки доказательством работы интерфейса, температурного режима и жестов на телефоне.

Исходная база0.3.2 получена из пользовательского ZIP; происхождение сохранено в docs/imports/. Android остаётся отдельным проектом, основной LocalPilot для ПК в my-agent не заменялся. Прежние документы README.ru.md и архивные handoff описывают исторические версии.
