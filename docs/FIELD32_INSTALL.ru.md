# LocalPilot Field 32 0.7.36 · отдельная тестовая установка

**Полный APK, без ZIP и удаления прежних установок:** LocalPilot_Field32_0.7.36.apk

- Пакет: `org.localpilot.android.field32`
- Название в меню: **LocalPilot Field 32**
- Отдельные настройки и данные, не обновляет Field 31, Field 30, Standalone, Preview или Dev.
- Исходная ветка исправлений: `fix/naschupai-protected-dynamite-20261030`, PR #35 поверх PR #32.
- Минимальный Android 11, подпись debug CI. Следующее обновление этим же именем пакета потребует тот же ключ, поэтому эта сборка рассчитана на самостоятельную проверку.

## Исправлено
1. **Цветной 2048:** распознаются светлые полупрозрачные пустые клетки на реальном фоне уровня. Внешние яркие неизвестные объекты блокируют действия.
2. **«Нащупай ход»:** теперь профиль `TRACE_LINE` вместо ошибочного `SWAP_MATCH3`. Черепа распознаются как непроходимые препятствия.
3. **Динамит:** при наличии *двух независимых частей*, красного цилиндра и жёлтой искры, клетка получает `PROTECTED_DYNAMITE` и недоступна для касания. Обычные цветные фишки не маркируются этим признаком на проверенных кадрах. Никакая палитра по динамиту не обучается.
4. **Частичная сетка:** допускается только прямая цепочка из 3+ устойчиво распознанных безопасных фишек при покрытии поля от 72%, подтверждённых двух независимых кадров и корректной привязке окна. Защищённые клетки/UNKNOWN/оверлеи не пересекаются. Частичные SWAP, TAP_GROUP, изогнутые линии остаются без ввода.
5. Android ACK не подтверждает ход: требуется фактическое визуальное изменение игры.

## Установка и тестирование
После скачивания APK установите LocalPilot Field 32 как **новое** приложение, не удаляя остальные. Выключите службу специальных возможностей старого LocalPilot и включите только Field 32; выберите Market, профиль и новую область ROI.

Примечание: симуляции и Android-эмуляторы проверяют сборку, служебную безопасность и тестовые сцены. **Они не доказывают, что все 10 игр работают на телефоне/планшете.** Реальное выполнение и корректность динамита требуют проверки на устройстве с новым APK. Уже выявленные проблемы с FLAPPY, ARKANOID и неопознанными иконками сохраняются в общем issue #29.

Контрольная SHA256 файла находится в отдельном `SHA256SUMS.txt` в релизе.
