# LocalPilot Standalone 0.7.34: установка рядом со старой версией

## Что исправляет сборка

При установке обычного `org.localpilot.android.dev` поверх существующего
приложения Android может сообщить «Приложение не установлено, так как оно
конфликтует с другим пакетом». Это ожидаемо при разных ключах подписи APK.
Команда `adb install -r` не может обходить проверку подписи.

Эта тестовая Standalone-сборка основана на исправленном RC1
`9d977d852e1ccb70a162abcf93b7dc3dd185980a` и использует
**отдельный идентификатор** `org.localpilot.android.dev.install1029`.
Имя на телефоне: **LocalPilot Standalone**. Это новая установка, а не обновление
существующего `org.localpilot.android.dev`.

## Как установить

1. Откройте GitHub Release `v0.7.34-dev-install1029` и скачайте
   `LocalPilot_Standalone_0.7.34.apk`, **не ZIP**.
2. Откройте APK из «Загрузок». Если Android запросит разрешение устанавливать
   приложения из этого браузера, разрешите для доверенного источника.
3. После установки откройте **LocalPilot Standalone**.
4. В специальных возможностях Android **отключите службу старого LocalPilot**
   перед включением Standalone. Никогда не оставляйте оба пилота активными
   одновременно, иначе они могут отправлять конфликтующие жесты.
5. Заново выберите игровой профиль, приложение/браузер и ROI. Новая версия
   имеет отдельное хранилище и НЕ переносит настройки или обучение старой.

Старое приложение и его данные остаются на устройстве. Не удаляйте его
до резервного копирования нужной информации.

## Проверяемые свойства

- Готовый APK, не source ZIP или workflow artifact.
- APK действительно подписан (`apksigner verify`).
- `aapt dump badging` подтверждает уникальный пакет и версию.
- CI Android-эмулятор устанавливает **оба пакета одновременно**, запускает
  Standalone и проверяет его наличие в PackageManager.
- Сертификат первого Standalone APK создаётся в изолированной CI-среде.
  **Будущие пересборки этого же пакета другим ключом не смогут обновить эту
  установку поверх**. Требуется устойчивый приватный ключ, хранящийся вне
  репозитория, для реального долгосрочного канала обновлений.

Это временный установочный тестовый вариант. Он не включает непроверенные
изменения PR #27 и не доказывает работу на физическом телефоне или планшете.
Нельзя обещать установку при недостатке памяти, ограничениях MDM/Play Protect
или ошибках системного установщика, которые не связаны с конфликтом подписи.
