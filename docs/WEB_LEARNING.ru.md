# Web-обучение · 0.7.0 Dev

Откройте «Web · варианты обучения», введите HTTPS-адрес игры и выберите один из трёх режимов. Это отдельный браузер внутри LocalPilot; он не управляет игрой в другом Android-приложении. Разрешения Accessibility и MediaProjection этому браузеру не нужны.

## 1. Запись собственных действий

1. Откройте игру по HTTPS и дождитесь загрузки.
2. Включите запись и играйте вручную; STOP завершает запись.
3. После минимум десяти примеров нажмите «Обучить», затем запуск модели.

Записываются нормализованные касания, удержания и перетаскивания, признаки изображения до/после действия; добавляется ограниченное число примеров ожидания. Данные сохраняются локально с резервной копией. Модель выбирает ближайший похожий пример и воздерживается при неизвестной или неоднозначной сцене. Это экспериментальное обучение по демонстрациям, а не универсальная нейросеть и не перенос DQN из симуляторов. Для независимой оценки нужны отдельные сеансы записи; совпадение действий не означает победы.

## 2. Импорт примеров

1. Откройте ту же игру по тому же HTTPS-адресу.
2. Выберите файл .lpweb через Android либо HTTPS-ссылку на него.
3. Нажмите «Обучить» и запустите модель.

Поддерживается только LOCALPILOT-WEB-v1, до1000 примеров/8MiB, с проверкой структуры и цепочки контрольных сумм. Импорт объединяет данные без дубликатов; другая игра или повреждённый формат отклоняются. Файл содержит256 RGB/delta-признаков; он несовместим с64 признаками native DQN. Адрес игры хранится как SHA256, открытым текстом экспортируется только origin; секреты в адрес игры вводить не следует. Контрольная сумма обнаруживает повреждение, а не доказывает достоверность источника.

Готовые реальные демонстрации не приложены: последний пользовательский audit ZIP имеет0байт. Тестовые данные не выдаются за реальные записи игры.

## 3. Подсказки интернет-модели

1. Настройте HTTPS OpenAI-compatible /chat/completions endpoint, ID vision-модели и свой ключ.
2. Нажмите «Подсказка»: снимок только web-области отправится выбранному API.
3. Проверьте предложение и нажмите «Применить»; изменившаяся сцена отклоняется.

Ключ не включён в APK. По умолчанию он действует в текущем сеансе; сохранение опционально через Android Keystore. Никакой автоматической передачи кадров выбранной Android-игры нет. Подсказка не запускает бесконечный облачный автопилот и может быть слишком медленной для аркады.

## STOP и ограничения проверки

STOP, ручное вмешательство и уход в фон выключают автоматические действия; незавершённый web-жест отменяется. Новая страница завершает текущую запись. HTTPS-страницы с несовместимым WebView, защищённым видеовыводом, входом в аккаунт или сложным управлением могут не работать. Нативные Arcade-профили остаются отдельными.

JVM-проверки формата, восстановления backup, ограничения данных, распознавания и HTTP-клиента выполнены. HTTP-тесты используют имитацию HTTPS: запросы к реальному провайдеру не выполнялись. WebView, PixelCopy, Keystore и реальные игры на телефоне ещё требуют проверки; собранный APK не является доказательством прохождения игры.
