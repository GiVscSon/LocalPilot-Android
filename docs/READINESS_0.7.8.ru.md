# Проверка работоспособности 0.7.8

Исправлены два подтверждённых дефекта кода:
- Чтение RGBA-плоскости и уничтожение ImageReader теперь используют один монитор. Отложенный callback после закрытия игнорируется до acquireLatestImage. Раньше главный поток мог освобождать native-буфер во время чтения потоком захвата. Это возможная причина сбоя, а не установленная причина пользовательского SIGSEGV без backtrace.
- Контроль остановки кадров действует после первого кадра даже до первого распознавания. Раньше отсутствие распознанной сцены отключало этот контроль бессрочно.

Новый RGBA-декодер проверяет размеры, stride и доступный диапазон до чтения; поддерживает padding и укороченную последнюю строку. JVM-тесты проверяют heap/direct буферы, ненулевую позицию, целостность результата, усечённые данные и неверные размеры. Сам lifecycle MediaProjection требует проверки Android.

## Запуск на телефоне
1. Установить APK обновлением, включить службу LocalPilot в специальных возможностях.
2. Открыть раунд игры; на панели выбрать «Окно» и соответствующую «Игру».
3. Нажать «Старт», подтвердить показ всего экрана и вернуться в игру. STOP остаётся доступен.

Неизвестная сцена не означает обучение универсальному зрению. Встроенные контроллеры поддерживают конкретные профили; автоматическое прохождение произвольной игры не реализовано. Обучение web отдельно от нативных профилей.

## Критерий приёмки на Android
- «Проверить касания» → «Начать проверку ×10»: десять попаданий в цель, а не только десять ACK.
- После разрешения захвата растут кадры и READ; затем решения, ввод и ACK.
- Движение персонажа подтверждается свежим кадром; STOP прекращает ввод.
- Проверить повторный старт/STOP и возврат из системного диалога без вылета.
- При отказе: «Отчёт с кадром игры». Native crash требует bugreport/backtrace: старые exit reason без стека не определяют виновную библиотеку.

Физическое устройство не подключено (adb devices пуст). Эти критерии пока НЕ пройдены на телефоне. APK нельзя называть полностью работоспособным на устройстве только на основании сборки/JVM-проверок.
