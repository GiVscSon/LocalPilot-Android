# Точка продолжения — диагностика игр, 30 октября 2026

Рабочая ветка: `fix/phone-diagnostics-20261030`, база `7037711`.
Версия Gradle — 0.7.34/code 50; debug — отдельный пакет
`org.localpilot.android.preview`. Версия установленного на телефоне APK
по предоставленным снимкам неизвестна.

По снимкам: в игре с осьминогом выбран режим прямой цепочки, а ранее
пользователь подтвердил обмен соседей. Для такого управления предусмотрен
профиль «Нащупай ход · обмен, избегать черепов». На двух снимках видна
остановка `TARGET_WINDOW_UNAVAILABLE`; их недостаточно для определения причины.
В цветном 2048 изображена уже существующая плитка 32; её номинал нельзя
устанавливать по неизвестному цвету без подтверждённой истории слияния.

Изменения: в локальную диагностику добавлены только агрегированные причины
отсутствия корневого окна (нет окон приложений, нет окна в фокусе, отсутствует
root или не совпадает его window ID). Сохраняются последние значения отказа;
идентификаторы, имена приложений и изображения не добавляются. Проверки
ActionGate, фокуса и владельца окна не ослаблены. Это диагностика, а не
подтверждённое исправление исчезновения окна.

Color2048Reader больше не принимает неоднозначный тёмно-серый цвет за синюю
16. Новые тёмные нейтральные цвета можно выучить лишь после полного
детерминированного перехода, при видимых светлых пикселях надписи и двух
устойчивых кадрах с последующим confirm. При каждом чтении тёмной плитки
повторяется проверка надписи; однотонная заслонка отклоняется. Цвета близкие
к базовой палитре и плитки, появившиеся до подключения, остаются UNKNOWN.
Синтетические проверки не доказывают применимость порогов к реальной игре.

release_tools — PASS; Upgrade726Verify — 135 проверок. Android Gradle

физический телефон и игровые кадры — NOT RUN. Для прежнего

APK несовместим с опубликованным Preview как обновление. Не удалять
установленное приложение и не очищать его данные. Стабильный релиз не заявлен.
