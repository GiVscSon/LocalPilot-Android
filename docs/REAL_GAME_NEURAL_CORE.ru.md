# LocalPilot-Android · реальная игровая нейросеть 0.8.1

**Версия APK:** `0.8.1-dev-install1081` (`versionCode 53`, `org.localpilot.android.dev.install1081`), отдельная установка рядом с `0.8.0`.

**Основа:** исходный код текущего Android-приложения и обучение по действительным событиям игрового движения. Отдельные настольные модели и репозиторий `LocalPilot` не модифицируются.

**Почему эта реализация:** ролик https://youtu.be/tihq_bLfk08 демонстрирует маленькую сеть, backprop и сохранение её весов при помощи Python+NumPy. Этот пример НЕ содержит обученной игровой сети. Реальные входы и действия взяты из имеющегося LocalPilot-Android.

## Реализованная сеть

Файл `RealGameNeuralCritic.java`:

- Архитектура: **24 нормализованных входа → 16 tanh → 1 sigmoid**, 417 параметров, без облачного API и зависимости от TensorFlow.
- Входы: реальные `ArcadeObservation` из `Vision V2` и специализированных детекторов: положение и размер персонажа/платформы, скорости, проход, ближайшее препятствие, уверенность, тип **конкретного предложенного жеста** и профиль игры.
- Раздельные экземпляры: Карканоид (PADDLE), Маркет Раш (TRAFFIC), Гошан (FLAPPY). У них одинаковая архитектура, но **раздельные веса и точные схемы действий**.
- Обучение: SGD/backprop по действительным парам **(наблюдение, предложенное действие, подтверждённый визуальный результат)**. Метка 1 возможна только после `ArcadeFeedback.verified` и проверки `ArcadePolicy.response`; метка 0 требует ACK и *следующий свежий распознанный кадр*, не показывающий результат действия. Просто Android ACK **не считается ни обучением, ни успехом**.
- Без подтверждённого результата новые веса **не изменяются**. Результаты из симулятора не помечаются как реальные.
- Применение: `ArcadeController.decide` вызывает модель после проверенного физического контроллера. Пока данных мало, она вообще не меняет политику. После накопления не менее 16 подтверждённых успехов, 12 подтверждённых неответов и 32 обучающих обновлений сеть **может только отменить очевидно неудачное действие**. Она не создаёт самостоятельных жестов и не меняет ROI.
- Веса сохраняются в `ArcadeLearningStore` как `NG1` + Base64(checkpoint с SHA-256), ключ `package + modelSlot + profile + .real-neural-v1`. Несоответствие версии, профиля, формы или контрольной суммы приводит к отказу от весов, без отключения стандартной игры.
- Обучение производится на устройстве без серверных запросов. Архитектура ограничена и не требует мощного GPU.
- Новый CI-тест `tests/RealGameNeuralVerify.java` использует действующие `ArcadeController`, `ArcadeLearningStore` и `ArcadePolicy`. Он подтверждает настоящие backprop-изменения, round-trip сохранения, изоляцию профилей, отклонение повреждённых весов и нулевое обучение по ACK без движения.

## Что использовано из накопленного материала

- **Vision V2** → согласованные кадры/временные метки/маски.
- **Object-centric** → компактные признаки объектов вместо необучаемого RGB-перебора.
- **WeightSpace + PaddleTransfer** → стартовая физическая/игровая политика, которую модель не может обойти.
- **Double DQN** → существующая лаборатория остаётся источником алгоритмов, но её несовместимые checkpoint не подменяются настоящими весами. Для неё нужен отдельный schema adapter.
- **Игровое зрительное подтверждение** → положительные/отрицательные метки привязаны к фактическому результату, а не к ОС.

## Статус и ограничения

Это новая реально обучаемая игровая сеть, встроенная в Android-обработчик для **трёх реальных аркад**. Она пока выполняет роль модели вероятности игрового отклика, а не полного независимого RL-актёра. Для Ари, Шипучки, 2048, сеточных игр, Гексона и Котобашни нужны собственные наблюдения и схемы действий. Загрузка оригинальных NVIDIA NitroGen и MIT/OpenAI-весов из видеороликов не произведена.

**Критически важно:** изменение веса, зелёный CI и синтетические тесты ещё не подтверждают, что модель улучшает результаты реальных игр. Для этого нужны аппаратные серии и сравнение результатов до/после при неизменных настройках.

Действуют STOP, ActionGate, InputPermit, TTL, Fail-Closed, PANEL_COVERS_ROI, CONSENT_TIMEOUT, UNKNOWN, protected-skull SWAP_MATCH3, единственный исполнитель и обязательное визуальное подтверждение. Issue #69 остаётся открытой.

## Как проверить

```bash
java tests/RealGameNeuralVerify.java
```

Критерий реальной приёмки: `ArcadeFeedback.verified` увеличивается **только** после нового игрового кадра, количество обучающих обновлений и счётчик реальных успехов сохраняются в отдельных checkpoint, а повреждённый checkpoint не влияет на физический контроллер.

Сохранён исходный базовый вариант: `archive/localpilot-android-0.8.0-before-neural-game-core-20261104`.
