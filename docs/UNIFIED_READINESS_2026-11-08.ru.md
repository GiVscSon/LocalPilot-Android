# LocalPilot: завершение пользовательских путей, 08.11.2026

Продолжение PR #90. Проверенный исходный кандидат сохранён в `archive/unified-before-readiness-20261108` (a8deb60371a4faafc8b1a7a77f33e2a6760519cc). Не подменять новую приёмку результатами старого SHA.

## Доступно в одном APK

- Главный экран → «Библиотека · 16 моделей и версии». Все 16 совместимых встроенных ZIP проверяются и копируются в отдельное лабораторное хранилище.
- Выбор профиля, импорт ZIP, экспорт выбранной версии, SHA256 и схема, выбор старой версии для отката, обучение выбранного или всех профилей, оценка на отдельных seed. До 16 неизменяемых версий на профиль; превышение лимита отклоняется, история не удаляется.
- Импорт проверяет все поля манифеста, точный профиль, схему наблюдений/действий/награды, число параметров, контрольные суммы, размеры и конечность весов. Дубликаты JSON-ключей и подложный game_id отклоняются. Испорченные версии отображаются; загрузка/экспорт и активация повреждённых весов запрещены.
- Выбранная LAB-версия не активирует реальный контроллер. Хранилище `lab-model-versions-v1` отделено от `adaptive-engine-v1` и Android ActionGate.
- Встроенный NES/Денди исполняет локальный JSNES. Новый адаптер записывает реальные framebuffer-наблюдения (64 яркостных признака), маску удерживаемых кнопок и номер эмулированного кадра, связывая эпизод с SHA256 ROM и отдельной сессией запуска.
- NES → «Экспорт опыта NES (.lpn)» → библиотека → «Обучить NES по эпизоду (.lpn)». Обучается ограниченная политика повторения наблюдённых кнопок для того же ROM; неоднозначные/далёкие состояния остаются UNKNOWN. Награда UNKNOWN, данные RETRO_EMULATED; это не перенос в настоящие игры и не RL-доказательство прохождения ROM.

## Внешние сайты и shadow evaluation

Добавлена команда существующего оркестратора:

```
python3 scripts/localpilot.py unified shadow --output build/reports/site-shadow
```

Требуются JDK17, Node.js с Playwright и Chromium. Путь Chromium: `/usr/bin/chromium`. Сеть использует настройки среды. Проверяются `https://2048game.com/` и `https://ovolve.github.io/2048-AI/` без входа в аккаунты. Решение рассчитывается по снимку и явно выбранному ROI; DOM используется только для независимой сверки распознанных чисел. После каждого браузерного хода новый снимок должен соответствовать правилам хода и одному новому тайлу. Модель сравнивается с базовой политикой в shadow-режиме; браузер управляется базовой политикой, модель ничего не активирует в Android.

Выполненный локальный прогон: на каждом сайте 13 прочитанных кадров и 12 последовательных визуально подтверждённых ходов, 0 несовпадений клеток, 13/13 совпадений shadow-решений с базовой политикой. Это проверка классической механики 2048 в браузере, не всех десяти реальных игр Маркета и не физического Accessibility.

На play2048.co обнаружен новый интерфейс без прежнего `.game-container`; перенаправление старого сайта Gabriele Cirulli ведёт туда же. Этот дизайн не засчитан как поддержанный. На 2048game.com подтверждён другой цвет пустых клеток: добавлен явный `CLASSIC_DARK_EMPTY`; стандартный режим и все прочие неизвестные цвета по-прежнему отклоняются. Скриншоты остаются в игнорируемом build/, в Git не добавляются.

## Проверки и выпуск

Добавлены JVM-проверки моделей/импорта/версий/отката/изолированного обучения/shadow и ROM-bound NES-эпизодов, negative tests неверного профиля/повреждённых данных/неизвестной палитры/неоднозначных кнопок. Для JSNES адаптер проверяется на настоящих CPU/PPU кадрах Homebrew ROM. В Android acceptance добавлено открытие библиотеки через видимую кнопку, загрузка 16 профилей и лабораторная оценка без arming ввода.

Итоговые результаты относятся только к HEAD из новых GitHub Actions и PR. Android build/JVM/Python/Lint/API30/35/36/APK integrity должны завершиться повторно. Gradle unit task NO-SOURCE не является выполненным JUnit-набором.

Релиз на физических устройствах остаётся открытым по issue #69: телефон и планшет этой среде по ADB не подключены. Сайты, браузерные коннекторы и синтетическая Android-матрица не заменяют минимум пять визуально подтверждённых ходов в каждой из десяти настоящих игр на телефоне/планшете. STOP/InputPermit/TTL/UNKNOWN/ROI и визуальная верификация не отключались. Нельзя автоматически объявить release_ready=true или закрыть #69.
