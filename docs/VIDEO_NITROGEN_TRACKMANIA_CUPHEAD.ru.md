# Три видео: NitroGen / Trackmania / Cuphead

**Дата проверки:** 2026-11-04. Этот файл сохраняет проверяемые исходники трёх присланных видео для LocalPilot на ПК и LocalPilot-Android. Он не означает скачивание весов или внедрение в установленный APK. Сводка видеостраниц опирается на заголовки/публичные описания; полная расшифровка и покадровый разбор этих трёх роликов на момент записи не получены.

## 1. «Заставил Нейросеть играть в Half-Life 2»
Видео: https://youtu.be/HR3Qr9WLpmQ

**Технология, названная в описании ролика:** NitroGen. Это модель NVIDIA/MineDojo, а не обученные автором видео веса для Half-Life 2.

**Проверенные первоисточники:**
- Статья: https://arxiv.org/abs/2601.02427
- Код: https://github.com/MineDojo/NitroGen
- **Официальный checkpoint:** https://huggingface.co/nvidia/NitroGen/blob/main/ng.pt
- Зафиксированная ревизия файла: https://huggingface.co/nvidia/NitroGen/blob/73a12a270889bda502d8a626cc7ed798c772710a/ng.pt
- SHA-256 файла (примерный размер **1,97 ГБ**; точный размер проверяется при скачивании): `a266f5fb9c7dbdcdf97216558d2d82075a9a994b824cda69afa9fd3280260a81`. В интерфейсе Hugging Face указан размер **1,97 GB**.
- Модель: 493 млн параметров, SigLIP2 visual encoder + DiT, 256×256 RGB → последовательность действий gamepad (21×16), 40 000 часов видео с более чем 1000 игр, **behavior cloning**, НЕ reinforcement learning от встроенной награды.
- Официальное ограничение из README: использует **только последний кадр**, не умеет самостоятельно планировать долгие траектории, проходить любую игру от начала до конца или самоулучшаться. Поддержан запуск Windows-игр; авторы проверяли Windows 11 / Python >=3.12.
- Лицензия `NVIDIA License`, **только некоммерческие исследовательские цели** (см. LICENSE). Нельзя молча включать веса в коммерческий Android-дистрибутив или называть их Apache/OpenAI.

**Что взять для WeightSpace:** имитационное предобучение на геймплейных демонстрациях, общий vision-to-action encoder и дистилляцию в лёгкие специфические политики. Прямая модель NitroGen использует gamepad, а не Android touch; для телефона требуется адаптер и тесты наблюдений/жестов. На пользовательской AMD RX 7600 XT выполнение через обычный GPU CUDA не подтверждено; сначала проверка backend и latency на ПК.

**Установка на ПК с подключённым интернетом после проверки лицензии:**

```powershell
py -m pip install -U huggingface_hub
hf download nvidia/NitroGen ng.pt --revision 73a12a270889bda502d8a626cc7ed798c772710a --local-dir "D:\\LocalPilot\\models\\NitroGen"
(Get-FileHash "D:\\LocalPilot\\models\\NitroGen\\ng.pt" -Algorithm SHA256).Hash.ToLower()
```

Ожидаемый SHA-256 указан выше. Команда **не выполнялась нами на компьютере пользователя**.

## 2. «Обучение непобедимого ИИ в Trackmania»
Русский ролик: https://youtu.be/KerqrfSUtFk

**Оригинал:** Yosh, 30 сентября 2023 года, https://youtu.be/Dw3BZ6O_8LY

**Подтверждено:** это история об обучении с подкреплением, повторных заездах, награде за улучшение траектории и времени, усложнении трасс; использовалась программная интеграция TMInterface. Публикации и обзоры описывают **reward hacking**: награда за дрифт привела к частому дрифту, а не к минимальному времени круга.

**Checkpoint именно Yosh из этого ролика:** **не обнаружен в проверенных открытых первоисточниках**. Не добавлять случайную модель с похожим названием.

Отдельный, **НЕ принадлежащий Yosh** открытый проект для изучения архитектуры и обучения:
- https://github.com/Linesight-RL/linesight
- https://linesight-rl.github.io/linesight/build/html/
Он предоставляет код для Trackmania, в том числе IQN и интеграцию с интерфейсом игры. Его веса **не следует выдавать** за веса из оригинального ролика.

**Для WeightSpace:** прогресс по маршруту и завершение уровня важнее отдельной «красивой» награды; вводить штраф за столкновение, ограничение на ложные события, curriculum по трассам и тренировку с отдельным held-out набором уровней. Применимо к Маркет Раш, Ари и платформерам после перевода в соответствующие координаты.

## 3. «😱Учу Нейросеть Играть В Cuphead!»
Видео: https://youtu.be/SAzDZhSSa_c (Роберт До Нила, 2026).

По публичному описанию **тема видео подтверждена**, но оно не раскрывает точный алгоритм, формат сети, checkpoint или репозиторий. Не утверждать, что автор использовал PPO, DQN или YOLO, пока не найден собственный исходник или запись кадров.

Независимые исследования **НЕ этого автора**:
- https://simonxcao.github.io/bots/final.html — Cuphead-проект с YOLO для обнаружения объектов и DQN для выбора действий. Это другой проект.
- https://github.com/Deinigu/cuphead-rl — отдельно опубликованная реализация sim-to-real PPO для Cuphead. Не считать весами видео Роберта До Нила до доказательства связи.

**Для WeightSpace:** выделение персонажа/босса/пуль, прогноз столкновений и временные последовательности, совместимый с настоящей игрой формат observation/action, reward за урон противнику и выживание одновременно. Отдельно обучать принятие решений при редкой награде; не засчитывать отправленный тап как доказанный уклон.

## Результат проверки источников

- **Из этих трёх новых видео: один независимо подтверждённый официальный доступный checkpoint (NVIDIA NitroGen).**
- Для двух других видео авторские checkpoint пока **не подтверждены**. Сохраняем ссылку на видео и проверенные альтернативные исследования **отдельно**.
- Из двух предыдущих видео в каталоге уже учтены 28 оригинальных наборов. Итого **29 ссылок на подтверждённые оригинальные наборы игровых весов** по всем пяти роликам (28 + один NitroGen), но файлы **не скачаны в GitHub LocalPilot, ПК пользователя или APK**.

## Правило переноса в Android

Не смешивать настольный LocalPilot и LocalPilot-Android; использовать только экспорт/импорт через зарегистрированные schemas. Ни один чужой checkpoint не должен получать право на Android-жест без корректного преобразования gamepad→touch, проверенной распознанной сцены, ActionGate/InputPermit/STOP/TTL/UNKNOWN и визуального подтверждения изменения в следующем кадре. Issue #69 требует приёмку десяти игр на обоих устройствах независимо от успеха на PC.
