# LocalPilot Android — 0.7.8 Dev

0.7.8: устранена гонка закрытия буфера захвата; зависший поток обнаруживается до распознавания игры. [Проверка работоспособности и запуск](../READINESS_0.7.8.ru.md). Проверка на телефоне остаётся открытой.

0.7.7: web-запись сохраняет награды и ошибки; ручные отметки + автоматический числовой показатель цели. Приближение даёт плюс,удаление — минус; неизвестный исход не объявляется успехом. Положительные примеры подсказывают действия,отрицательные блокируют похожие ошибки. [Правила и ограничения](../REWARD_LEARNING.ru.md).

0.7.6: новая панель с выбором окна/профиля, отдельная прямоугольная область игры, удаление боковых полей и просмотр последнего захваченного участка. Кнопки отладки перенесены в «Ещё». [Три шага запуска](../WINDOW_PANEL_2026-10-21.ru.md). [Что полезно из GitHub](../GITHUB_PROJECTS_REVIEW_2026-10-21.ru.md). Проверка на физическом телефоне ещё нужна.

0.7.5: исправлены пороги распознавания Ари для уменьшенных кадров и фильтр жёлтого тела на бежевом фоне; запуск захвата ожидает готовности службы перед закрытием окна разрешения; окно прозрачное. При STOP из-за смены окна показывается точный код причины. Проверка по двум новым видео: [подробности](../VIDEO_CAPTURE_HANDOFF_2026-10-21.ru.md). Поведение на физическом Android ещё не проверено.

0.7.4: web-обучение разделено по явным профилям игр, даже если мини-игры открываются на одном URL. Кнопка «Игра ▾» выбирает набор; при смене профиля запись/игра останавливаются, модель и кадр сбрасываются. Новые .lpweb-v2 содержат имя и ID профиля. Старые v1 сохраняются отдельно, не используются автоматически для обучения/ввода и доступны для экспорта или переноса копии проверенного сеанса. Лимит1000 примеров теперь относится к каждому профилю отдельно. Отчёт обучения показывает покрытие на оставленной сессии.

0.7.3: добавлен контроль пропавшего callback жеста: через3с исполнитель освобождается с диагностикой, запоздалый ответ не меняет новый жест. «Проверить касания» → «Начать проверку ×10» запускает проверку попаданий без ручной привязки панели. «Отчёт с кадром игры» сохраняет единый ZIP с последним игровым кадром, состоянием распознавания/жестов, параметрами устройства и диагностикой сбоя. Кадр удерживается только в RAM и записывается лишь по явной кнопке экспорта; автоматической отправки нет.

0.7.2: автоматический поиск потерянной сцены. LocalPilot перебирает исходную, более светлую и более тёмную обработку новых кадров; после двух подтверждений автоматически возвращается к управлению. Удалены остановка через2.5с неизвестной сцены и блокировка распознавания Ари после трёх промахов. Повторная обработка действует внутри выбранного профиля; поддержку неизвестной игры она не гарантирует.

0.7.1: диалог захвата вынесен в отдельную временную Android-задачу, чтобы после подтверждения возвращаться к игре, а не главному окну LocalPilot. В момент возврата допускается обновить ID только того же приложения и тех же границ; после начала игры смена окна по-прежнему вызывает STOP. Для «Карканоида» исправлена путаница красного шара с тёмным рисунком деревянного блока. Если сцена не распознана, панель сообщает, какой объект не найден. Проверка Android-перехода на физическом телефоне ещё требуется.

0.7.0: запуск профиля в три шага, автоматическая привязка при выборе игры и ожидание начала раунда. Захват ограничен по памяти; при повторном вылете доступен «Экспорт диагностики сбоя». Добавлено отдельное меню «Web · варианты обучения»: запись собственных действий, импорт примеров и подсказки интернет-модели. Проверка на физическом телефоне ещё не выполнена.
