# Начальный поиск Bubble без цветовой маски

Продолжение PR #27 после 31fab0f. BubbleObjectVision.find сканирует ограниченную сетку RGB-пикселей по геометрии: радиальные границы, заполненный круг, подгонка окружности по краевым точкам, ошибка радиуса и подавление повторных кандидатов. Таблица оттенков не участвует в предложении пушки или рядов. У изолированной пушки используется внешняя граница, чтобы светлая спираль не задавала радиус. У плотных рядов разрешены частично скрытые дуги, но сохраняется проверка подогнанной окружности.

В BubbleVision удалены цветовые компоненты, морфологическое закрытие, их рабочие массивы и сильный цветовой порог. Цветовой класс читается после подтверждения объекта. Геометрия рядов требует согласия не менее 85% опорных окружностей и малой ошибки; неподдержанные клетки по-прежнему отклоняют всё чтение. Кандидаты с геометрией за ROI не принимаются.

Первый поиск может превышать 300 мс. PilotService сохраняет только геометрическую подсказку сразу после успешного чтения; старый кадр не получает разрешение на действие. Следующий кадр заново читает все клетки и пушку. BubbleSession всё ещё требует два свежих устойчивых кадра, а исполнитель — прежние TTL/session/window/ROI/ACK проверки. Дедлайны не расширены.

Локально: 72 проверки формы и поиска, 264 board/policy/feedback, 1476 независимых проверок отскоков PASS. Частный размеченный кадр: 603 проверки, ровно 58 шаров и зелёная пушка при масштабах 0.75/1/1.5, повторные чтения совпадают. Первый поиск в песочнице имеет переменную длительность; это не измерение быстродействия телефона. Исходные кадры не публикуются.

Тест координат API30 теперь сравнивает центры с независимой геометрией рисующей фикстуры и точностью дискретизации, вместо побитового повторения старого алгоритма подгонки. Независимая проверка целочисленного жеста, фактического попадания в клетку 18 и точного ожидаемого удаления сохранена.

Android CI нового SHA требует отдельной проверки; предыдущие три зелёные матрицы 31fab0f не относятся к новому коду. Физическая игра NOT RUN. Обратные ряды остаются наблюдением без ввода. Сопровождение произвольных объектов и неизвестных игр не объявляется готовым.

Повторение: java tests/BubbleVerify.java; полный набор JVM/tooling указан в .github/workflows/android.yml. Текущие native результаты — в PR #27.
