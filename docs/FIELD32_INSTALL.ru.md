# LocalPilot Field 32 · 0.7.36 · отдельная интеграционная проверка

Пакет org.localpilot.android.field32, code52, метка LocalPilot Field 32. Полный APK ставится рядом с Dev, Preview, Standalone, Field30 и Field31; их данные не удаляются и автоматически не переносятся. Включать только одну службу LocalPilot одновременно.

Объединены две расходившиеся линии: Field31 cb3ad456 (пустые полупрозрачные клетки 2048, профиль Нащупай ход TRACE_LINE, защищённый частичный прямой ход и метрики отклика) и Bubble 95c3fb0 (поиск объектов без цветовой маски, текстурированная пушка, восстановление геометрии после изменения изображения). Сохранён cancelUnsent из Field31 и его измерение времени ACK→VERIFIED; добавлена ранняя геометрическая подсказка без разрешения ввода по старому кадру. Инструментация синхронизирована с существующим ожиданием окна; производственные сроки не расширены.

По приложенным файлам: полный JPEG 2048 прочитан как [0,0,2,0; 0,4,4,0; 0,0,0,0; 0,0,0,0]. ROI для этого воспроизведения выбран вручную. Два JPEG 6×6 с ROI из диагностического архива, пропорционально пересчитанным к уменьшенным изображениям, дают partialUsable=true, по четыре UNKNOWN, без слияния разных распознанных предметов и без принятия черепа за обычную фишку. Использована новая палитра, не отсутствующий в архиве сохранённый пользовательский профиль. Пиксели и сырые частные журналы в репозиторий не включены.

Архив подтверждает установленный org.localpilot.android.preview, sdk36, работающий захват/accessibility, 27 PANEL_COVERS_ROI и 120 PARSE_REJECTED за время жизни службы. Это не количество ошибок текущей игры. LAST_STOP=TARGET_BOUNDS_CHANGED, последнее чтение 6×6 имело RING_NO_MATCH и NO_SAMPLE; сохранённого Java-падения нет. Экспорт не содержит кадра игры. Высокие ACK не доказывают выигрыш или правильное управление.

В начале виден отказ свежести кадра, затем запрос согласия. Из этой записи нельзя вывести точные нажатия или причину нулевого счёта Гошана: это другая игра. Нужна её временная последовательность с наблюдаемым прыжком и препятствием.
