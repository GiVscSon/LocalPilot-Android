# Награда Game Over 0.7.16-dev

Экран результата с кнопкой «Играть снова» распознаётся как terminal. Последнее неподтверждённое действие не считается успехом: параметры контроллера получают штраф, а профиль Ари уменьшает дальность следующего риска и увеличивает требуемую точность. Обновлённая модель сохраняется до начала следующего раунда и загружается при новом сеансе.
