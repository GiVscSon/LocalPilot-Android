# LocalPilot Android 0.7.27-dev / code43

Устанавливается поверх прежней Dev-версии: org.localpilot.android.dev,
прежний сертификат подписи; пользовательские данные не удаляются.

## Изменение конфигурации

PilotService сравнивает физические размеры дисплея, rotation и densityDpi.
Изменение метаданных конфигурации при прежней геометрии не останавливает игру.
Реальный поворот, изменение размера хотя бы на один пиксель, плотности или
ошибка получения геометрии по-прежнему отзывают ввод и требуют новой привязки.
Обычные проверки фокуса, ID/границ целевого окна и возраста кадров сохранены.

Новый DisplayGeometryTest проверяет положительные и отрицательные варианты.
Нативная проверка во время настоящего демо-жеста вызывает callback конфигурации
с изменёнными dp/шрифтом, затем требует прежние epoch/разрешение ввода и
завершение десяти реальных касаний. Это инъекция callback, не эмуляция Game Turbo.
Отдельный прежний сценарий действительно поворачивает Android и проверяет STOP.

## Диагностика приёмки

В отчёт тестов добавлены время сбоя, списки окон UiAutomation и службы,
а также состояние Android ActivityManager на изолированном эмуляторе.
Это позволяет различать отсутствие Activity, потерю фокуса и неполное дерево
Accessibility. Успешный ACK не подменяет проверку видимого результата.

Окончательные результаты и ограничения: VALIDATION_0.7.27.txt.
Поддержка новых жанров и качество игры на физическом телефоне этим выпуском
не заявляются. Все изменения 0.7.26 сохранены.

## Задержанные снимки и меню

Кадр с истёкшим ticket/TTL, повторным timestamp или системным ограничением
частоты снимков отбрасывается без ввода; до трёх раз запрашивается новый снимок.
Ни старый кадр, ни старый ticket не переиспользуются. После свежего кадра счётчик
сбрасывается; при повторном исчерпании лимита остаётся явный STOP. Ошибки
разрешений, геометрии и сессии не маскируются повтором. Предел 700 мс сохранён.

Меню панели снимает своё окно ввода перед запуском выбранного действия.
Обработчик запуска переносится на следующий проход UI-потока; анимация
закрытия служебного меню отключена, чтобы первый игровой жест не попал в него.

## Начальная привязка окна

Корень Accessibility принимается только при совпадении его windowId с ID
фактически сфокусированного окна. Кнопка проверки касаний ждёт до двух секунд
публикации непустых границ и маркера тестового поля. После привязки повторно
сверяются пакет, ID и границы; до этого нет разрешения ввода. STOP/новая сессия
отменяют ожидающий запуск по epoch, переход в чужое приложение не запускает
проверку. Это исправляет наблюдавшийся на API30 отказ «Нет границ окна».
