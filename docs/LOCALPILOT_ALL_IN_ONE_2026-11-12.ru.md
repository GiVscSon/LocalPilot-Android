# LocalPilot All-in-One: один Android APK вместо трёх

**Статус:** тестовый кандидат, НЕ стабильный релиз. Новый вариант собирается исключительно
из исходников одной ревизии через `-PunifiedModelLab=true :app:assembleDebug`.
Он имеет временную debug-подпись, отдельный тестовый package ID
`org.localpilot.android.dev.unified` и НЕ обновляет приложения с иными сертификатами.
Пользовательские данные прежних установок НЕ удалять ради обновления.

## Единый APK / один ярлык
- **LocalPilot**: основной экран, пользовательский выбор игры, управление через
  имеющийся AccessibilityService; STOP, ActionGate, InputPermit, TTL и визуальная
  верификация не ослаблены.
- **GameLab**: уже встроенные 10 игровых симуляторов, настоящая NES/Денди с
  предоставленными ROM и только проверенные homebrew ROM. Состояния симуляторов
  не признаются автоматически реальными наградами игр Маркета.
- **ModelLab**: внутренний экран (не экспортируется, не имеет отдельного
  launcher) с реальной импортируемой/скачиваемой GGUF-библиотекой,
  проверкой SHA-256 и размера, ручным mmproj/VLM-анализом выбранной фотографии
  или переданного NES-кадра. Чтение фото не разрешает агенту игровые жесты.
- **Одна JNI-библиотека** `liblocalpilot_embedded.so`: CPU-first llama.cpp
  с защищённым последовательным доступом. Нет второго класса с таким JNI
  именем в app APK; standalone ModelLab оставлен для регрессионных тестов.

## Размер APK и совместимость
Веса GGUF не вшиваются в тестовый All-in-One APK. Память под модель
потребляется только после её загрузки из UI. Native ARM64 JNI требует
Android API 30+, т.е. целевое устройство POCO X7 Pro поддерживается по ABI,
но реальная работа ещё НЕ подтверждена. MNN/ONNX/TFLite в данном режиме
не являются совместимыми GGUF и не заявляются как работающие runtime.
Vulkan GPU **не включён** в этот CPU-first вариант, пока драйверное
ускорение не будет проверено на физическом телефоне.

## GitHub Actions
Workflow `LocalPilot All-in-One · GameLab + ModelLab (test-only)`:
проверяет исходный контракт; загружает точно зафиксированную ревизию
llama.cpp; компилирует ARM64 JNI и Java; проверяет пакет, один launcher,
наличие NES, ModelLab, JNI, отсутствие встроенных весов и валидную debug-подпись;
загружает **только тестовый артефакт** и контрольные суммы, не публикует GitHub
Release. Манифест `TEST-ONLY-MANIFEST.json` содержит `releaseReady=false`.

## Требования к настоящему релизу
1. Один **постоянный** защищённый PKCS12 для `org.localpilot.android`.
   Предыдущий debug APK несовместим с обновлением под новым ключом, поэтому
   необходим согласованный пользователем экспорт/импорт, а не uninstall.
2. Signed `release` APK с публичным SHA-256 отпечатком, pinned source commit,
   подписанными контрольными суммами и тестом неразрушающего обновления
   с *предыдущей версией, подписанной тем же ключом*.
3. CI для нужной версии на одном SHA. Ручные испытания на POCO X7 Pro:
   импорт GGUF, повторная CPU генерация, mmproj+настоящее фото,
   GameLab NES → ModelLab, STOP, возобновление, поворот экрана,
   сохранность моделей и результатов обучения.
4. Полевая проверка существующей цепочки управления играми. Отсутствие
   подтверждённого движения после Android ACK должно оставаться STOP.
5. Не сливать и не маркировать как stable при невыполнении пунктов.

Три отдельных проекта в репозитории могут оставаться CI/SDK тестовыми целями,
но владельцу для работы требуется **один пользовательский APK**.

план подписи *трёх* пакетов; его не смешивать с финальным планом одного APK).
