# LocalPilot Android 0.7.31-dev / code47

Шипучка теперь выбирает между прямым выстрелом и одним отражением от боковой
стены, когда оно даёт лучший рассчитанный результат. Для рикошета жест
наводится на первую стену, а ожидаемое поле вычисляется по финальному
попаданию: совпадение от трёх шаров и падение отсоединённых гроздей.
При равных результатах предпочтителен прямой путь.

Планировщик требует согласованной геометрии всей ширины поля. При обрезанной
или смещённой области отражения отключены. Касания рядом с двумя целями,
скользящие столкновения и второй отскок отклоняются. Два устойчивых свежих
кадра требуются до действия и после доставленного Android жеста; ACK сам
по себе не подтверждает попадание. При несовпадении поля следующий выстрел
приостанавливается.

## Запуск

1. Установить поверх предыдущей Dev-версии, без удаления приложения.
2. Открыть раунд Шипучки, выбрать окно и профиль обычных шаров.
3. Обвести всю ширину игры вместе с верхними шарами и пушкой. Оставить место
   для STOP. Нажать «Готово» и «Старт».

На панели различаются «Прямой выстрел» и «Один рикошет». Бомбы, радужные
шары, пробивающий луч, запасной снаряд и несколько отражений пока не
автоматизированы. Профиль остаётся экспериментальным.

## Все десять игр

[Справочник механик](GAME_MECHANICS_REFERENCE.ru.md) сопоставляет присланные
описания с фактическими адаптерами. Для доски с осьминогом сохранён обмен
соседей с защитой черепов; описание цепочек этому противоречит и не меняет
управление автоматически. Гексон и Котобашня по-прежнему требуют отдельных
контроллеров. Награды акций и выполнение квестов за минуту не гарантируются.
