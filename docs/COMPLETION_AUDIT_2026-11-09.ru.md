## Исправления

- Полный `unified all` теперь действительно выполняет BUILD → TEST, а не проверяет заранее оставшийся APK. Команда `build-test` повторно использует фактические JVM-команды android.yml, запускает Python contracts, Gradle, NES CPU/PPU и адаптер наблюдений. Сохраняет команды, выходные коды и SHA256 логов; отсутствие Gradle JUnit-source фиксируется как NO_SOURCE.
- Итоговый APK сверяется с build-test receipt. Метаданные `localpilot-build.json` связывают бинарный файл с точным Git SHA и содержимым отслеживаемых исходников; SHA виден в приложении и диагностике. При несовпадении публикация кандидата отклоняется.
- Повреждённый указатель выбранной модели не скрывает исправную историю и не блокирует ручной откат. Повторный импорт исправной версии может восстановить повреждённый объект, сохраняя повреждённую копию. Выбор файла переживает инициализацию/пересоздание Activity. Экспорт сначала проверяет источник, затем открывает назначение.
- NES export сначала валидирует снимок и его схему, затем открывает документ. Обработаны отмена/сбой/повторный экспорт и устаревшие callbacks другой ROM-сессии.
- HexaSession сверяет полный ожидаемый результат размещения и нужный слот лотка, а не любую перемену на поле. Предсказанное очищение не считается наблюдавшимся результатом.
- KotobashnyaFeedback требует свежие кадры после ACK, отскок вверх и исчезновение цели для stomp. Движение камеры и отдельная анимация плиты не считаются успехом.
- Android acceptance расширен до API30/35/36 × phone(pixel_2)/tablet(pixel_c). Профили подтверждены SDK. В отчёте сохраняются API, SHA, размеры/dpi, smallest-width dp и явный признак эмулятора; телефонная геометрия не выдаётся за планшетную.

- В live Arcade/Jumper подтверждение теперь требует кадр строго после timestamp ACK; без ACK таймаут закрывает ввод. Кадр между отправкой и ACK не может выдать VERIFIED.
- HexaVision больше не читает количество плиток из alpha-битов и не подставляет 4/3 по умолчанию. Невидимые высоты остаются UNKNOWN; положительный тест планировщика использует отдельно заданное поле, не выдаётся за распознавание реального снимка.

## Реальная граница поддержки

Наличие 16 моделей в APK не означает 16 подключённых настоящих игровых контроллеров. У Гексона и Котобашни остаются лабораторные модели/симуляторы и проверяемые helper-классы, но их capture/policy/action маршруты не подключены в PilotService. Экран моделей теперь явно это показывает. DOS/SEGA — синтетические профили без ядер; NES имеет локальный JSNES и отдельный ROM-bound опыт. Для остальных восьми перечисленных игровых механик существуют внешние визуальные контроллеры, но полевая приёмка всех десяти игр на телефоне/планшете не выполнена.

Эти ограничения не устранить переименованием статуса, успешным unit test или допуском непроверенного жеста. Issue #69 остаётся открытым до необходимых полевых доказательств. STOP, ActionGate, InputPermit, TTL и fail-closed сохраняются.

## Повторяемый прогон

```
python3 scripts/localpilot.py unified all --require-sdk --output build/reports/completion
python3 scripts/localpilot.py unified shadow --output build/reports/completion
```

Первая команда собирает и проверяет APK на текущем checkout; вторая отдельно проверяет два публичных сайта 2048. Браузерный результат не является физической Android-приёмкой. Итоговые отчёты этого изменения должны относиться к новому SHA, указанному внутри APK.
