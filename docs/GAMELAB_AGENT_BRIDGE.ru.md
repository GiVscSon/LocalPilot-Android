# GameLab → LocalPilot: учебный replay bridge v1

## Реализованная интеграция

GameLab (отдельный APK, package `org.localpilot.gamelab`) регистрирует **реальные Android-касания только в упрощённых сценах** через `GameSurface.onTouchEvent`. Перед жестом и после него фиксируются отпечатки состояния `GameLabEngine.fingerprint()` и результат `CHANGED / NO_CHANGE / BLOCKED`.

Новая кнопка **«Опыт GameLab → LocalPilot (учебный CSV)»** сохраняет через Android Storage Access Framework отдельный файл `localpilot-gamelab-replay-v1.csv` с ограниченным синтетическим форматом. Обычный диагностический CSV остаётся без изменений.

В основном приложении **«Игровые модели · обучение и экспорт»** появилась кнопка **«Импортировать опыт из GameLab (CSV)»**. Она проверяет весь файл до изменения данных, создаёт отдельно хранимый учебный `gamelab-shadow-v1.txt`, обучает таблицу эмпирических вероятностей изменения состояния для пяти классов действий (TAP/LEFT/RIGHT/UP/DOWN) и показывает только **подсказки**. Сохранение атомарное; один и тот же журнал учитывается один раз по SHA-256.

## Инварианты безопасности и честной приёмки

- Журнал несёт обязательный маркер `synthetic-only`, источник `GAMELAB_SIMULATED`, строгий game/profile и проверяемую пару state hash/outcome.
- Опыт при неисправностях `INPUT_IGNORED`, `FROZEN_VIEW`, `PANEL_OVERLAP` не обучает prior; `BLOCKED` не считается подтверждённой сменой состояния.
- Файл ограничен 256 KiB / 512 событиями, координаты и продолжительность жеста проверяются; неизвестные версии, игры, результаты и поля отклоняются целиком.
- Нет автоматического `PilotService.dispatchGesture`, `InputPermit`, `ActionGate`, изменения `RealGameNeuralCritic`, `ArcadeLearningStore` или правил `countsForMarketAcceptance`.
- Перенос в реальные веса потребует отдельной оценки на реальных наблюдениях с Android ACK и свежим кадром; этот PR не утверждает, что перенос уже работает.

## Проверка без ADB

1. В GameLab открыть игровой симулятор и сделать несколько движений.
2. Нажать «Опыт GameLab → LocalPilot (учебный CSV)» и сохранить файл на планшете.
3. В LocalPilot открыть «Игровые модели · обучение и экспорт» и нажать «Импортировать опыт из GameLab (CSV)».
4. Проверить изменившиеся статистики учебной модели, выполнить повторный импорт (должно быть «Этот журнал уже импортирован»).
5. Убедиться, что настоящий Market не получал жестов, а его нейросетевые веса и сертификаты приёмки не изменились.

## Автотесты

`java tests/GameLabReplayVerify.java` проверяет чтение записей, обучающий счётчик, устойчивую дедупликацию, восстановление модели, запрет подмены источника/профиля/результата и отказ от повреждённого файла. Включён в `Build Android debug APK` до упаковки APK.

## Следующий этап (не включён)

Калиброванный перенос sim→real возможен только после доказанной совместимости реальных экранных признаков, дополнительного теста на настоящих играх и сохранения всех защитных ограничений. NES/Денди в текущем мосте сохраняет отдельную ветку исполнения и пока не экспортирует training replay игрового CPU.
