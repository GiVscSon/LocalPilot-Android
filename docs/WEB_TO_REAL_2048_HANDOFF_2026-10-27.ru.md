# LocalPilot Android: перенос Web-обучения в настоящую игру 2048 (27.10.2026)

## Задача
Пользователь отметил, что обучение в отдельном экране «Web · реальные демонстрации и подсказки» работает отдельно от контроллеров игр. Это **не одна общая обучаемая нейросеть**. Web-уроки LOCALPILOT-WEB-v3 хранят 8x8-признаки до/после жеста, нормализованные касания и ручные/метрические оценки. Реальные игры используют отдельные консервативные контроллеры (Grid, 2048, Arcade, Bubble) с проверкой результата. Переносить необработанные пиксели или координаты между ними нельзя.

## Первый реально подключённый мост: Web 2048 -> Android 2048
- После записи/импорта примеров, постановки результата «Оценка / цель» и «Обучить» в WebLearningActivity пользователь **явно нажимает** кнопку «В реальный 2048».
- Допускается только **именованный профиль «2048»**; требуется минимум 10 оценённых направленных свайпов, из них 5 положительных. Неоценённые записи, тапы, диагональные/короткие жесты, чужие игровые профили исключаются.
- WebLesson.graded2048Directions считает только направления векторов и метки outcome; Web2048Transfer кодирует ограниченную статистику 4 направлений вместе с SHA256 идентификатором исходной страницы. Хранятся агрегаты в SharedPreferences `real-2048-transfer`, ключ `model`. Raw pixels, пользовательская URL, координаты, sample rows **не копируются** в 2048-модель.
- PilotService.start2048 загружает выбранную модель только в рамках текущей сессии стандартной или цветной механики 2048 и **после её явного включения**; ошибка формата = исходный CPU-планировщик без переноса.
- Board2048.chooseWithBonus прибавляет максимум +/-0.4 к оценке уже **легальных** направлений; не переопределяет геометрию, цели, запреты, снимки, InputPermit, ActionGate, focus/STOP, TTL или post-ACK проверку. Обучение не заменяет реальный результат; Android ACK не считается выигрышем.
- Пользователь видит в предварительном просмотре 2048 количество перенесённых оценённых жестов. Через ту же кнопку «В реальный 2048» открывается диалог с «Использовать» и «Отключить перенос» (также доступно, если обучение ещё не подготовлено). Отключение удаляет только ключ `real-2048-transfer.model`; все `.lpweb` уроки и остальные модели остаются нетронутыми. Действующий 2048-сеанс нужно перезапустить, так как prior считывается при старте. **Не очищать данные APK**, иначе будет потеря опыта.

## Тесты и ограничения
- tests/Web2048TransferTest.java проверяет контроль источника, 10+ оценок, fail-closed на нерелевантном профиле, непроверенных примерах, недопустимых направлениях, bounded bonus, сериализацию и применение к legal 2048.
- tests/Verify.java содержит этот JVM-тест; GitHub workflow Build Android debug APK выполняет регрессионные проверки на HEAD.
- Физический POCO X7 Pro: NOT RUN. Достоверные игровые победы: NOT VERIFIED. Другие игровые механики пока не связаны с WebLesson, так как их признаки и действие не совместимы с 2048; не навязывать им направления по аналогии.
- Рабочий PR #10 https://github.com/GiVscSon/LocalPilot-Android/pull/10 (base integration/panel-grid-20261027). PR #8 и PR #9 остаются отдельными.
- Защита фокуса: тест раннего восстановления до первой неподтверждённой команды; если pending swipe уже был, сохранён fail-closed STOP. Во втором демо размещение STOP-панели исправлено; отдельный тест проверяет непрекрытие цели.
