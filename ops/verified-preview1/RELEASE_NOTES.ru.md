**LocalPilot Preview 0.7.34** — отдельная установка для проверки на телефоне.
Пакет: `org.localpilot.android.preview`, версия `0.7.34-preview`, code 50.
Требуется Android 11 или новее.

Если Dev APK выдавал «пакет конфликтует», Preview устанавливается как другое
приложение рядом со старым LocalPilot. Старое приложение и его данные удалять
не нужно. Палитры, профили и обучение автоматически в Preview не переносятся.

Перед запуском нажмите STOP в старой версии и отключите её службу Accessibility.
Затем включите службу **LocalPilot Preview**, выберите игру, окно и область
заново. Не запускайте две службы LocalPilot одновременно.

Исходный коммит Preview: `1961f29c2b2cf6c29b40b007dbb8442814a95914`.
Игровая логика и исправление сохранения Bubble-подтверждений взяты из `9d977d8`.
Изменены идентификатор/название приложения и выбор компонентов тестового раннера
из Gradle-конфигурации. Защиты STOP, ActionGate, InputPermit и проверка
визуального результата сохранены.

Три отдельные матрицы API 30/35/36 для точного Preview SHA:
[прогон 1](https://github.com/GiVscSon/LocalPilot-Android/actions/runs/40944359211),
[прогон 2](https://github.com/GiVscSon/LocalPilot-Android/actions/runs/40944446833),
[прогон 3](https://github.com/GiVscSon/LocalPilot-Android/actions/runs/40944450870).
Итоговые результаты содержатся во вложенном `ACCEPTANCE.json`.
APK публикуется без пересборки и переподписания из
[CI-сборки](https://github.com/GiVscSon/LocalPilot-Android/actions/runs/40944359214).

Физическая приёмка телефона ещё не подтверждена. Это Preview-предрелиз, а не
обновление старого пакета и не стабильная 0.7.34. Инструкция установки,
сохранность старых данных и ограничения подписи описаны в
`INSTALL_AND_ACCEPTANCE.ru.md`. Редкий
[SCREENSHOT_TIMEOUT](https://github.com/GiVscSon/LocalPilot-Android/issues/24)
остаётся открытой диагностируемой проблемой.

В прогоне 3 первая попытка API30 завершилась безопасной остановкой `ACK_TIMEOUT`; полный повтор на том же SHA прошёл. Исходный отказ сохранён в `ACCEPTANCE.json`. Устранение периодической задержки ACK не заявляется.
