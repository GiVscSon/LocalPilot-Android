# Обучение 0.7.14-dev

Реальные аркадные сеансы теперь автоматически сохраняют обученную модель движения в `arcade-learning-v1.log` внутри закрытого хранилища приложения. При запуске службы модель загружается по профилю Ари, Карканоида, Маркет Раш или Гошана. Сохраняются только подтверждённые визуальным ответом действия; Android ACK сам по себе не считается обучением. После Game Over следующий раунд продолжает физическую модель.

Для 2048 прежнее хранилище `experience-v1.log` продолжает работать отдельно. Локальные логи, ключи и видео в APK не включаются. Это адаптация физических параметров, а не обучение нейросети; качество на конкретной игре требует нескольких подтверждённых раундов.
