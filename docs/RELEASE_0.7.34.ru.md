# LocalPilot Android 0.7.34-dev

Исправлена проверка дробных и нечисловых координат жеста до преобразования в
целое число. Превью скриншота больше не обновляется из устаревшего сеанса или
после потери фокуса. При краткой потере фокуса состояние ожидающего сеточного
жеста сохраняется. Для подтверждения хода проверяются изменения клеток,
связанных с ожидаемым результатом, на устойчивых кадрах после ACK.

Сохранение моделей при нескольких экземплярах хранилища синхронизировано:
записи других профилей и счётчики не теряются, а повреждённый файл не
перезаписывается молча. Совместимость Dev-пакета и подписи сохранена.

Проверка изменений сетки остаётся эвристикой: совпадающие цвета после заполнения
могут привести к безопасной паузе, а пространственная корреляция не доказывает
причинность. Проблемы перекрытия области, неизвестных фишек и управления всеми
играми не объявляются решёнными. Физический телефон не проверен. Спецификация
PATCH_SPEC ожидает отдельной команды; её непроверенные гипотезы не внедрены.
Подробности: VALIDATION_0.7.34.txt и AUDIT_0.7.34.ru.md.
