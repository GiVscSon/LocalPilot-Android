# Отдельная установка LocalPilot Preview

Основа игрового кода: `9d977d852e1ccb70a162abcf93b7dc3dd185980a`.
Пакет Preview: `org.localpilot.android.preview`, версия `0.7.34-preview`,
versionCode 50, минимальный Android 11 / API 30.

Preview устанавливается рядом с прежним `org.localpilot.android.dev`.
Это обходит конфликт подписей разных APK с одинаковым пакетом, не удаляя
старое приложение. Данные, палитры и обучение старой версии остаются в её
собственном пакете; в Preview они автоматически не переносятся. Для обновления
самого старого пакета по-прежнему нужен его исходный ключ подписи.

Перед запуском Preview нажать STOP в старой версии и выключить её службу
Accessibility. Затем включить службу **LocalPilot Preview**, заново выбрать
приложение, окно и игровую область. Две службы одновременно не запускать.
Старое приложение не удалять и данные не очищать.

В списке целей Preview исключены собственный пакет, `org.localpilot.android`
и `org.localpilot.android.dev`: новая служба не должна управлять старой.

Изменены только идентификатор/метка APK и определение компонентов тестового
раннера по существующей Gradle-конфигурации. Правила жестов, STOP, захвата
и визуального подтверждения остались от проверенной основы. Прогон матриц
Preview нужно учитывать отдельно: прежние проверки Dev не доказывают
установку нового пакета или его работу на физическом телефоне.
