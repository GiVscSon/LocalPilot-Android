# LocalPilot-Android 0.7.35 experimental (install1035)

**Ветка версии:** `release/v0.7.35-experimental`. **Не stable-релиз** и пока не подтверждена работоспособность всех десяти игр на двух реальных устройствах.

## Объединённые изменения

- #71 / PaddleWeightLab: физический эксперимент Карканоида, четыре сравниваемые политики, ручной ограниченный patch весов.
- #72 / PaddleTransfer: восемь вариантов физики, независимая оценка, тренировка и явный перенос совместимой малой сети в *настоящую модель* ArcadeController профиля Карканоид. При отсутствии визуального подтверждения действует автоматическое отключение переноса, Android ACK не считается успехом.
- #73 / WeightSpaceSkills: прямое программирование ограниченных матриц для Ари / Маркет Раш / Гошана, одиночная правка весов для синтетического выхода из тупика, автоматические проверки регрессий. Это пока **тестовые учителя, не самостоятельные авторизованные игровые политики**.
- #73 / JumperWeightShadow: чтение настоящих `JumperState` и сравнение исходной и исправленной матриц только в теневом режиме. Результат показан в игровой диагностике, но **не заменяет действующее решение и не отправляет жесты**.
- #73 / TextRepetitionGuard: отклонение повторяющихся ответов онлайн-vision-учителя до появления подсказки о жесте. **Не изменяет Qwen**.
- Установлены регрессионные Java-тесты и матрица Android API 30/35/36.

## Версия и обратная совместимость

```
versionName 0.7.35-dev-install1035
versionCode 51
applicationId org.localpilot.android.dev.install1035
```

Debug-версия имеет **другое имя пакета**, чем `org.localpilot.android.dev.install1034` из старого APK. Их можно хранить одновременно. Учтите, что разрешения AccessibilityService и MediaProjection у них раздельные: на время испытаний включайте службу только нужной версии.

### Сохранённые точки отката

- Рабочий код до объединения weight-space: `backup/v0.7.34-before-weightspace-20261104` → `0c858658747828a49255b8ce874e2e0f62e9e5fa`.
- Предыдущее состояние `main`: `backup/main-before-v0.7.35-20261104` → `9b81e4a6dfe3afee1f18969b981f0c8d29f9b8e5`.
- Исходный `main` не переписан и не перемещён.

**Откат на устройстве:** отключить AccessibilityService версии `install1035`, STOP, открыть прежнюю версию `install1034` и включить её собственную службу. Состояния и модели между пакетами не переносятся автоматически. Откат Git-ветки не означает откат установленного на телефоне приложения.

## Приёмка

Требуется CI на **одном HEAD SHA**: Build, JVM, Android unit/lint, API 30/35/36, корректный APK fingerprint/подпись. Затем 10 игр × 2 устройства × 5 последовательных визуально подтверждённых игровых действий после ACK. Не выдавать симуляцию, API-инструментальные тесты или успешную упаковку за физическую приёмку.

PANEL_COVERS_ROI, CONSENT_TIMEOUT, фокус, protected-skull SWAP_MATCH3, защита UNKNOWN, STOP, ActionGate, InputPermit, TTL, Fail-Closed и visual witness остаются обязательными. Issue #69 остаётся открытой.

Файлы APK можно скачивать только из успешного GitHub Actions запуска этой ветки с названием артефакта `LocalPilot-Android-<exact SHA>`, после проверки SHA и пакета. До завершения сборки новую версию нельзя объявлять устанавливаемой.
