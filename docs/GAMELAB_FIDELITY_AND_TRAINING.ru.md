# GameLab: действительная функциональность и приёмка игровых механик

## Три разных обучающих контура

**1. GameLab Android: диагностические игровые стенды, НЕ тренажёры копий Маркета.**
Есть десять оригинальных представлений игровых механик с настоящим Android
сенсорным вводом. Приложение регулярно вызывает `tick()`, а пользователь
может отправлять `gesture()`. Таймер не превращает их в обученного агента.
Результат `simulatedChanges` не является наградой настоящей игры.
Нельзя считать такой результат подтверждением реального ввода.

**2. LocalPilot Android: четыре собственные DQN-аркады.**
`TrainingActivity` запускает `DqnTrainer` для JUMPER, PLATFORMER, LANES,
JETPACK. Есть собственные `ArcadeEnv`, память переходов, обновление весов,
сохранение ZIP checkpoint, отдельная оценка на 50 эпизодах. Это обучение
внутри учебной среды, а не по снимкам игр Яндекс Маркета. Выход из Activity
ставит обучение на паузу: автономная фоновая тренировка не обещается.

**3. NES Agent Lab: реальное выполнение iNES-ROM через CPU/PPU JSNES.**
Первый изолированный сценарий обучения и проверка видеоданных существуют в
PR #91. Android NES-плеер в GameLab действительно исполняет ROM, но
подключение обученного checkpoint непосредственно к его кнопкам пока
не реализовано. Нельзя представлять ROM любого жанра как одну общую задачу
с универсальной наградой.

## Исправления стендов 2048, Шипучки и Карканоида

* 2048: одно объединение плитки за ход, правильное направление,
  новая плитка **только после реального изменения сетки**,
  равновероятный выбор среди свободных позиций,
  90% значений 2 и 10% значений 4. Счёт растёт только от объединений.
  Для диагностики есть отдельный **автоходовый baseline**, который
  не обучается, не пишет DQN-награды и не влияет на игру Маркета.
* Шипучка: выстрел теперь моделирует траекторию с отражением от боковых
  стен, установку шара при контакте, удаление группы 3+ одинаковых и
  отделившихся шаров. Это **приближение**: бустеры и все свойства
  оригинальной игры не калиброваны.
* Карканоид: физический мяч теперь сталкивается с теми же блоками,
  которые показывает Canvas, разрушает их и получает очки за
  столкновение, а не за касание декоративной верхней линии. Это
  **приближение**: скорость/углы/приближающиеся препятствия оригинала
  ещё не восстановлены по настоящим видеокадрам.
* Прыгун Ари, Гошан, Маркет Раш, Гексон, Котобашня,
  Мэтч Ворлд и защищённая сетка пока остаются
  **синтетическими испытательными сценами**. Даже правильное касание
  не доказывает реалистичность их игрового процесса.

## Критерий перехода к настоящему обучению на игровом симуляторе

1. Есть воспроизводимый визуальный эталон игры, достаточный для проверки
   объектов, управления, физики, экранов проигрыша и выигрыша.
2. Эквивалентность действия подтверждена: одно и то же действие
   в эталоне и симуляторе даёт проверяемо совместимое изменение.
3. Награда вычисляется из правильно определённого изменения игровой
   сцены, а не из Android ACK, количества касаний или просто tick.
4. Есть separate train/evaluation seed, контрольные эпизоды,
   saved checkpoint и реплей, без подмены SIM → REAL.
5. На телефоне протестированы реальные касания и кадры, отдельно от
   зелёных JVM-тестов.

## Скриптовая проверка в GitHub Actions

```bash
java tests/GameLabContractVerify.java
java tests/GameLabPhysicsVerify.java
java tests/ArcadeManualVerify.java
```

Дополнительно есть Android device acceptance API 30/35/36
и NES CPU/PPU smoke. Успешный CI необходим, но не является
подтверждением сходства стендов с играми Маркета.

**Рекомендованная основная лаборатория:** реальный NES-эмулятор
с визуальными задачами и наблюдаемым результатом, а не улучшение
непроверенных Canvas-копий до произвольной «похожести».
