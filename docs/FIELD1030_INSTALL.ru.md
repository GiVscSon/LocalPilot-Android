# LocalPilot Field 30 · отдельный APK от 30.10.2026

Это **полное Android-приложение**, а не патч, исходники или ZIP.

## Совместимость с уже установленными сборками

- Новый Android package: `org.localpilot.android.field1030`.
- Название в меню: **LocalPilot Field 30**.
- Версия `0.7.34-field1030`, код версии 50.
- Исходная база `fix/phone-diagnostics-20261030` (`7037711ea40ee3355d842fa5b87c55413dc69d10`): замеры визуального отклика, разовый снимок памяти, консервативное распознавание новых фишек.
- Не затрагивает `org.localpilot.android.dev`, `org.localpilot.android.preview` и `org.localpilot.android.dev.install1029`.
- Новая копия имеет отдельные настройки, калибровку и обученные примеры.

## Установка

1. Открыть GitHub Release `v0.7.34-field1030`, скачать **LocalPilot_Field_0.7.34.apk**.
2. Установить приложение Android (не пытаться обновлять старый APK).
3. Отключить службу специальных возможностей **старого** LocalPilot, затем включить службу **LocalPilot Field 30**. Две копии с активными AccessibilityService могут одновременно отправлять жесты и мешать друг другу.
4. Выбрать браузер/приложение, профиль игры и область ROI. По возможности использовать кнопку «Отчёт с кадром игры» для анализа на настоящем планшете.

## Ограничения

Этот APK устанавливается как **новое приложение**, а не переносит данные или модели из старых копий. Проблемы десяти реальных мини-игр не объявляются устранёнными: есть только синтетические и эмуляторные тесты, а игровая калибровка на физическом планшете ещё требует подтверждения. Подключение локальной VLM не включено.

Подписан и проверен в CI. Для дальнейшего **обновления именно этой копии поверх** нужен тот же ключ, поэтому данный APK предназначен для отдельного тестирования. Другой ключ в будущем нельзя использовать для обновления того же package; новую независимую копию можно выпускать с другим уникальным package.

## Требования к опубликованному APK

CI должен построить полный APK, проверить CRC, package ID, versionCode, minSdk, цифровую подпись, запустить его в Android-эмуляторе и только после этого опубликовать пререлиз с прямым .apk и SHA256. Старые приложения и их данные не удалять.
