# LocalPilot Android 0.7.33-dev / code49

Экспериментальный профиль «Шипучка» может продолжить игру, когда после
подтверждённого предыдущего хода остался один обычный шар и в пушке находится
шар того же цвета. Первый ход создаёт пару; если следующий шар совпадёт,
контроллер может собрать тройку. Поле и результат каждого хода по-прежнему
должны быть подтверждены свежими кадрами.

При другом цвете пушки или пустом поле ввод не отправляется. Первичное
распознавание по-прежнему требует нескольких видимых шаров; одиночный шар
поддерживается только при ранее распознанной геометрии поля. Бонусы и все
варианты игры не поддерживаются. Проверка на физическом телефоне не проводилась.

Устанавливайте поверх предыдущей Dev-версии без удаления данных. Подробности
проверок — в VALIDATION_0.7.33.txt.
