## Что это объясняет в нашем случае

Текущий нативный LocalPilot не содержит универсальную обученную нейросеть для любых игр. Есть четыре зрительных эвристических профиля и отдельные решатели полей. Web-обучение по примерам и обучение в симуляторе не превращают эти профили в универсальный детектор Android-игр. Если область окна неверная, видна собственная панель или цвета/формы не соответствуют профилю, счётчик READ может расти без решений. Завершение жеста Android не доказывает, что игра отреагировала правильно.

## Уже добавлено в рабочую версию0.7.6

Выбор реального Android-окна со списком приложения/размеров; границы AccessibilityWindowInfo вместо предположения, что root-node равен окну; отдельная область внутри окна (произвольный прямоугольник), автоматическая попытка убрать одинаковые одноцветные боковые поля, просмотр последнего захваченного участка. Единая область применяется распознавателем, преобразованием координат касаний и диагностикой. Строгая привязка к приложению/окну сохраняется. Основная панель сокращена; действия для отладки вынесены в «Ещё». Это наши реализации, не импорт библиотек этих проектов.

## Следующие полезные изменения

1. Редактор образцов: показать Ари/шар/платформу/кнопку на реальном кадре, хранить с названием игры и масштабом. Несколько кадров/ракурсов; положительные и похожие отрицательные примеры.
2. Дополнительный matcher по форме/текстуре в ROI с поиском нескольких масштабов и явной оценкой совпадения. Сравнить с цветовым детектором на наших видео, прежде чем делать его основным. Template matching не гарантирует устойчивость к анимации/повороту/перекрытию.
3. Временной трекер, стабилизация объектов по нескольким кадрам и визуализация ошибок. Для игры без подтверждённого игрока — повторное наблюдение/выбор области, для распознанной сцены — быстрый цикл управления.
4. Набор реальных проверок: запуск захвата, неправильное окно, боковые поля, поворот, фон, STOP, потеря кадров, завершение раунда. Измерять правильность объектов и ответ игры отдельно от ACK.
5. Только после этого — дополнительный VLM/модель для классификации неизвестной сцены. Измерять задержку и расход памяти на телефоне; низкочастотное объяснение сцены не должно задерживать быстрый контроллер аркады.
