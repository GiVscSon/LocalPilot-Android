# Аналоги и применённые решения — 20 октября 2026
Проверены первичные README и лицензии: Mobilerun (бывший droidrun), X-PLUG/MobileAgent, Genymobile/scrcpy, google-research/android_world, официальный API AccessibilityService. Сторонний исходный код или веса в APK не копировались; новые реализации написаны внутри LocalPilot. Ссылки ниже фиксируют просмотренные main/master, они могут изменяться.

Mobilerun: https://github.com/droidrun/mobilerun — MIT. UI trees+screenshots, typed mobile-native tools, workflow planning. В LocalPilot применено ограниченное сочетание UI marker своей мини-игры со screenshot ROI, раздельные профили и один исполнитель. Не установлен Portal/Python agent/облачный SDK; это не перенос их модели и не заявка на их benchmark.
Mobile-Agent: https://github.com/X-PLUG/MobileAgent — MIT. В README v3 описаны planning/progress/reflection/memory. Применён принцип отдельной проверки результата: стандартный переход2048, legalX/O+одинответсоперника, точныйtoggleLightsOut. Это детерминированные verifier, не LLM reflection и не импорт self-evolving learner.
scrcpy: https://github.com/Genymobile/scrcpy — Apache2.0; https://github.com/Genymobile/scrcpy/blob/master/doc/control.md. Из разделения наблюдения/управления взят read-only default. Нативный Accessibility executor остаётся собственным; USB/ADB streaming/remotecontrol не включены. scrcpy требует внешнего контроллера и не заменяет standalone phone runtime.
AndroidWorld: https://github.com/google-research/android_world — Apache2.0. Воспроизводимые задачи и независимые reward signals. Применены seeded synthetic fields, cross-language rules parity и отдельная проверка исхода. Сам AndroidWorld/эмулятор benchmark не запускался; результаты не сопоставимы с его leaderboard.
Android API: https://developer.android.com/reference/android/accessibilityservice/AccessibilityService. Сохранены платформенные ограничения, secure capture error не обходится. Не заявлена отмена уже отправленного жеста. ScreenshotResult uptime не смешивается с elapsedRealtime, callback receipt не равен выигрышу.

Из текущего аудита реализованы одноразовые tickets сissuer, отдельный InputPermit с budget/expiry, private fsync metadata journal с checksum/readback/sizecap и ошибкой fail-closed, отключённая debug-подключаемость APK. Без контактов/сети/экспорта кадров. Приватный журнал не заменяет verified feature store для PPO, не подтверждает causality при вмешательстве пользователя и не защищает от root.
Проверки:13gate+6131board/reader/clock/parity+2634hardening/mini assertions PASS; JavaAPI35/aapt2/d8/zipalign/apksigner PASS. Device installation/capture/input/Stop/игроваяприёмка/тепловыеизмерения/GradleCI не выполнены. В дальнейшем — реальный demo matrix, более широкий detector/модели on-device лишь после этого.
