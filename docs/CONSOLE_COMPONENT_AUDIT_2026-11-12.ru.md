# Проверка совместимости компонентов LocalPilot Console AI Lab
Дата: 12 ноября 2026. База: Draft PR #113, HEAD `34a07b8e0be6618cf2b9f600a93abebdee5f2145`.
**Уровень доказательности:** анализ исходников + GitHub CI на базе, не физический запуск GGUF на POCO X7 Pro.

## Исполняемый путь внутри одного APK
MainActivity → RetroLibraryActivity → NesEmulatorActivity (JSNES + реальная ROM)
→ `retroSnapshot()` PNG 128x120 → внутренний Intent → ModelLabActivity
→ ModelLabStore (проверенные GGUF/mmproj) → EmbeddedGgufRuntime (CPU)
→ строгий `ConsoleAgentContract` → одноразовый `ConsoleAgentGate`
→ `retroAiTrial(button,16)` внутри NES → ACK кнопки **не считается успехом**
→ новый кадр → `NesTrial` (PIXELS_DIFFER/NO_VISUAL_CHANGE)
→ `console-ai-episodes.jsonl` → **теперь** `ConsoleEpisodeContext`:
последние четыре проверенные записи **той же модели и того же SHA**
попадают в подсказку при следующем решении. Вознаграждение `UNKNOWN`.

Это **повторное использование опыта** в промпте, а НЕ изменение весов GGUF и не доказанное RL-обучение. Эпизоды другой модели или повреждённые строки не используются. Встроенная NES homebrew ограничивает автоматический ввод; пользовательские ROM без агентного допуска.

## Компоненты: ревизия
- **NES / Денди:** реальная офлайн-эмуляция JSNES, закреплён **2.1.0** и SHA-512 npm-архива; по официальным releases текущая версия. Денди лишь совместимый режим 50 Гц, не точная аппаратная модель.
- **ModelLab:** реальный GGUF JNI llama.cpp с проверкой SHA-256 весов, выбор модели и отдельный mmproj для vision. Выбранная модель теперь имеет конкретное использование в одном экспериментальном NES-ходе; модель без vision делает **слепое предложение**. Реальное качество и скорость на POCO ещё неизвестны.
- **Контроллер:** отдельный проверяемый ограниченный `BUTTON=...`, одноразовый токен, TTL, epoch, STOP, контроль свежих кадров; не делегирует Android-Accessibility модели.
- **Опыт:** bounded JSONL и ограниченный контекст для той же модели, теперь используется. Отсутствуют валидированная игровая награда, replay buffer с сохранённой парой состояний, оптимизатор, обучение весов. Называть это обучением весов нельзя.
- **Vulkan:** для отдельного ModelLab ARM64 есть CI native-linkage с `libvulkan.so`; `app/build.gradle` единого APK явно `VULKAN_COMPILED=false`. Наличие SDK и линковки не доказывает выполнение на мобильном GPU. Требуются отдельные ARM64 unified-билд и физический тест.
- **Другие консоли:** DOS только проверяет файлы. GBA/SNES/GB/PS1 и работающие ядра **не встроены**. Не показывать их как исполняемые.
- **Legacy TrainingActivity:** обучает старые аркадные/симуляторные политики; не загружает NES episodes, не обучает GGUF. Устаревший сектор, переносить или архивировать только после отдельного контракта сохранения.
- **Яндекс-мини-игры:** главный вход перенаправлен на консоли, но legacy Java / Python код и старые CI-процедуры всё ещё присутствуют. Их автоматические PASS не доказывают обучение NES.
- **Документация:** `README.ru.md` начинается с 0.7.11; не отражает Console AI Lab. Нужно обновить главным введением, сохранив старую историю.
- **Подпись:** экспериментальный debug APK нового package `org.localpilot.android.dev.unified`. Изменение debug-ключа может помешать обновлению с сохранением данных. Отдельный стабильный релиз и физическая приёмка не подтверждены.

## Версии сборочного стека
- **Android Gradle Plugin 8.7.3 + Gradle wrapper 8.9:** старая, но официально совместимая пара (AGP 8.7 требует минимум Gradle 8.9). На 12.11.2026 актуален Gradle **9.9.1**, ветка AGP 9.x. Не заменять глобально без отдельного PR с той же CI-матрицей и JNI/Vulkan сравнением.
  Official: https://developer.android.com/build/releases/about-agp
  https://docs.gradle.org/9.9.1/release-notes.html
- **JSNES 2.1.0:** текущий релиз по https://github.com/bfirsh/jsnes/releases
- **llama.cpp:** фиксированный исходный Git SHA `2b66bfbf7107e43f5cd2fe99802ff6e872e4c4d0`, более новые pre-release сборки 2026 доступны. Перед обновлением проверить API JNI, GGUF/VLM, Vulkan и STOP; никакого автоматического ребейза на moving HEAD.
- **Android compile/target SDK 35; min SDK 30, NDK 27.2.12479018, CMake 3.22.1:** сборка подтверждена CI, Android 16 устройство отдельно.

## Правила приёмки перед стабильным релизом
1. Host audit `tools/console_system_audit.py` PASS и настоящее Android CI API30/35/36 + единый APK API35 UI PASS на одном SHA.
2. Реальный POCO X7 Pro: загрузить GGUF/mmproj, зафиксировать модель ID+SHA, запустить test homebrew, получить корректный ответ `BUTTON=`, исполнить, проверить кадр, повторить 20 раз; журнал именно этой модели должен влиять на следующую подсказку.
3. Проверить STOP на генерации, возвращение из ModelLab, сворачивание NES, истечение TTL, смену ROM; никаких запоздалых действий.
4. GPU: реальная индикация Vulkan backend и ускорение/откат CPU на одинаковой модели с замером latency/RAM/температуры. CPU fallback не выдаётся за GPU.
5. Настоящее обучение весов требует проверенного reward и отдельной реализации; не считать запись эпизодов обучением.
6. При установке с другим debug-сертификатом сначала явно предупреждать о потере моделей/эпизодов.
