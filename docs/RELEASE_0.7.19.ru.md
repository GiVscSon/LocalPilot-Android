распознавания и управления для двумерных игр с известной механикой.

## Первичная настройка другой игры

1. Откройте игру, выберите профиль на панели. Через «Область → Выделить прямоугольник»
   выделите активное поле: для Машины — дорогу с тремя полосами; для Птенца —
   область полёта до пола, без панели счёта и нижнего интерфейса.
2. «Ещё → Настроить распознавание». Подтвердите захват Android, если запрошен.
   Укажите три объекта на замороженном кадре: шар/платформа/блок; своя машина/
   препятствие/второе препятствие; птенец/верхнее/нижнее препятствие.
   Для одинаковых препятствий можно указать один объект повторно.
3. «Ещё → Способ управления», выберите касания или свайпы, затем «Старт».
   При следующем сеансе настройки загружаются автоматически. В разных играх
   одного браузера используйте разные имена через «Игра → Имя игры».

«Ещё → Вернуть стандартное распознавание» отключает пользовательскую калибровку
текущей игры; сохранённые модели других настроек не удаляются.

## Поведение при неопределённости

Выбор объекта опирается на заданную точку, затем на предыдущую позицию.
Два почти одинаково вероятных игрока, пустое поле или закрытый панелью игрок
не дают разрешения на ввод. Невалидная конфигурация требует повторной настройки;
она не заменяется случайным распознавателем. Старые задачи анализа не могут
применить результат после смены конфигурации. Окончание раунда ищется во всём
игровом окне, поскольку карточка результата может находиться за пределами поля.

## Ограничения

Это сегментация различимых цветных объектов, не универсальная нейросеть.
Схожий с фоном цвет, текстуры, анимационные перекрытия, множество одинаковых
объектов, нестандартные механики и 3D могут требовать другого распознавателя.
Машина предполагает три полосы; управление наклоном не добавлено. Калибровка
использует три опорных цвета, а не распознаёт смысл произвольных объектов.
Детектор окончания раунда по-прежнему ориентирован на белую карточку с широкой
жёлтой кнопкой. Самообучение ограничено адаптацией физических параметров и
учётом исходов; рост результата от каждого раунда не гарантируется.
На физическом Android эта новая настройка в облачной среде не проверялась.
Решатели для новых снимков с сетками 6×6/7×7 и пузырьками в эту версию не входят;
их последовательные задачи сохранены в рабочем промпте.
