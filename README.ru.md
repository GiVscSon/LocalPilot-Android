## Запуск игры — три шага

При первом запуске включите службу кнопкой «Включить управление» и покажите панель.

1. Откройте игру.
2. На панели LocalPilot выберите название игры.
3. Подтвердите «Показать экран» и начните раунд.

STOP прекращает управление. Системное подтверждение захвата Android обязательно. Если приложение закрывается, откройте его снова и нажмите «Экспорт диагностики сбоя».

Web-игры открываются отдельно через «Web · варианты обучения». Три режима и ограничения: [Web-обучение](docs/WEB_LEARNING.ru.md).

## «Прыгун Ари»

1. Откройте в Яндекс Маркете мини-игру и оставьте её на экране.
2. На панели LocalPilot нажмите «Прыгун Ари»: привязка выполняется автоматически.
3. Разрешите Android захватывать экран. Во время игры видны системный индикатор захвата и уведомление STOP.
4. Если распознавание не уверено, разверните панель → «Калибровка Ари», затем отметьте на стоп-кадре Ари, оранжевую платформу и красный шип.

Кадры обрабатываются в памяти. Автопилот выбирает касание левой или правой зоны, затем проверяет движение персонажа. При потере сцены распознавание повторяется автоматически. Потеря окна или неподтверждённое движение останавливают управление. STOP есть на панели и в уведомлении Android.

Распознавание построено по цвету и форме объектов. Калибровка цветов хранится локально для выбранного приложения. Первую версию нужно проверить на самом телефоне: облачная сборка не подтверждает совместимость захвата, касаний и темпа игры с конкретным устройством. Эта политика не использует обученные симуляторные DQN веса.

## Новые игровые профили

Откройте раунд в Яндекс Маркете → название игры на панели → разрешите захват Android. «Карканоид» двигает корзину под шар, «Маркет Раш» касается левой/правой стороны для объезда машин, «Гошан» касается экрана для подъёма в проход между стопками. Панель сворачивается, STOP остаётся видимым. После каждого ввода проверяется движение. «Диагностика» открывает состояние со STOP.

Проверка выполнена на видеокадрах, без отправки жестов в настоящую игру. На вашем телефоне нужно подтвердить управление и темп каждого профиля.

## Остальные функции

- Обучение на телефоне для JUMPER, PLATFORMER, LANES и JETPACK; сохранение/экспорт полных checkpoint.
- Авто2048, крестики-нолики и Lights Out для поддерживаемых профилей. Для внешней цветной сетки есть экспериментальный режим с ручным выделением поля и цветовым распознаванием плиток2/4/8/16; неизвестное значение останавливает ввод.
- Журнал действий без кадров; приватные модели и исходные скриншоты не входят в репозиторий и APK.
