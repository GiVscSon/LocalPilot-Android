# LocalPilot Android 0.7.29-dev / code45

## Что изменилось

- **«Нащупай ход» — обмен соседей, 6×6.** По уточнению пользователя используется
  обмен двух соседних фишек. Добавлен отдельный профиль с распознаванием черепа
  на красной клетке: светлая голова, два тёмных глаза, нижние кости и фон должны
  согласоваться. Череп получает защищённую клетку, которая не участвует ни в
  обмене, ни в совпадении. Неизвестная клетка по-прежнему задерживает ввод.
- **Поля с фишками.** Допускаются до 12 различимых обычных типов, лучше читаются
  цветные предметы на нейтральной подложке. Особые клетки исключены из действий:
  контрастный центр сам по себе не доказывает, что это полезный бонус.
- **Прямые цепочки.** Отдельный режим «Фишки · провести прямую цепочку» проводит
  один непрерывный свайп по горизонтальной, вертикальной или диагональной цепочке.
  Минимум по умолчанию — три фишки. Ломаные пути этим режимом не строятся.
- **«Маркет Раш».** Машина игрока ищется по нижнему положению и размеру, а не
  только красному кузову. Красная небольшая канистра с тёмной ручкой отделяется
  от машин. Контроллер рассматривает её как цель только при безопасном прогнозе
  соседней полосы. Распознанные машины остаются препятствиями.
- **Цветная 2048.** Цвета 32…2048, изученные по подтверждённому слиянию и двум
  устойчивым кадрам, автоматически сохраняются и загружаются для того же
  приложения и имени игры. Появление меню отменяет незавершённое обучение,
  сохраняя подтверждённую палитру. «Ещё → Вернуть стандартное распознавание»
  сбрасывает только палитру выбранной цветной игры.
- **Выбор игры.** Служебные пункты меню не считаются сохранённым игровым профилем.
  Профиль с черепами хранит настройки отдельно от обычного Match-3.

## Как запустить на телефоне

1. Установить APK поверх прежней Dev-версии и открыть нужную игру.
2. На панели выбрать «Окно», затем «Игра». Для осьминога выбрать
   **«Нащупай ход · обмен, избегать черепов»** и размер **6×6**; для цветных
   строительных фишек — **«Мэтч Ворлд · обмен соседей»**, **7×7**.
3. В «Область» отметить два противоположных угла всей сетки, нажать «Готово»,
   затем «Старт». Панель не должна закрывать клетки. На экране результата
   нажать «Играть снова» самостоятельно.

Для разных игр в одном приложении/браузере задавайте разные имена через
«Игра → Имя игры · отдельное обучение». ADB для использования не нужен.
Цветная 2048 использует известную базовую палитру; произвольная цветовая тема
не становится распознаваемой от одного выбора профиля.

версиях игры. Для цепочек оставлен отдельный явно выбираемый режим.

## Проверки и ограничения

Два пользовательских снимка 6×6/7×7 проверены на трёх масштабах с ручной
разметкой типов фишек. На 6×6 защищены все три черепа и найден обмен, который
создаёт четыре листа. Эти проверки не отправляют жесты и не измеряют очки игры.
Пользовательские изображения не входят в репозиторий и архив исходников.

Сохраняются проверки окна, свежести кадра, токена жеста и визуального ответа.
ACK Android не является успехом игры. Подробные результаты сборки, JVM и
Android-приёмки находятся в [VALIDATION_0.7.29.txt](VALIDATION_0.7.29.txt).

Пакет `org.localpilot.android.dev`, прежний Dev-сертификат и пользовательские
данные сохраняются. Работа на физическом телефоне и улучшение рекордов ещё
не подтверждены. Это dev-итерация, а не заявление о поддержке всех десяти игр.
