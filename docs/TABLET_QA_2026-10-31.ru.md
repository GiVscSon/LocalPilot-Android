# LocalPilot Tablet QA · 31.10.2026

Это **экспериментальный APK для тестирования на реальном планшете**, а не стабильный релиз и не гарантированная работа всех десяти игр.

## Почему отдельное приложение
- Application ID: `org.localpilot.android.qa.tablet1031`.
- Display label: `LocalPilot Tablet QA`.
- Version: `0.7.34-qa-tablet1031`, versionCode 50.
- Сборка из ветки `install/tablet-qa-20261031` основана на PR #39 и временном PR #40. Включает увеличение детализации MediaProjection на планшетах, безопасную проверку геометрии ROI 2048, изоляцию старой калибровки, карантин изменений браузерного UI и ожидание 80 мс для двух подтверждающих кадров.
- Отличается отдельным packageId от установленного `org.localpilot.android.dev.install1029`, оригинального Dev и Field33. Существующие пользовательские данные старых пакетов не затрагиваются и **автоматически не мигрируют**.
- Подпись CI генерируется заново: дальнейшие сборки **того же** QA packageId могут не обновляться поверх этого APK; для ещё одного QA варианта нужен другой packageId или сохранённый постоянный signing key. Не удалять оригинальные приложения ради установки этого QA.

## Установка и безопасность
1. Получить APK из верифицированного GitHub Actions артефакта **конкретного коммита**, не из старого release по случайной ссылке.
2. Выключить Accessibility Service **всех остальных LocalPilot** перед включением LocalPilot Tablet QA. Два контроллера одновременно недопустимы.
3. Выбрать нужное игровое окно, профиль и ROI заново. Старые калибровки не переносятся.
4. Сначала проверить STOP без игры и показать/скрыть панель. При любой ошибке области, чужом окне, отсутствии свежего кадра должны быть отсутствие касаний и STOP/PAUSED.
5. Для одной аркады и одной сеточной игры собрать локальный «Отчёт с кадром игры» после ручного согласия на его содержимое. Никакой автоматической отправки скриншотов или иных данных нет.
6. В тесте отличать Android ACK от **двух подтверждённых новых кадров и реального игрового результата**. Зафиксировать 1 и затем 5 VERIFIED действий. При ошибке/паузе остановить ввод, а не увеличивать число автоматических попыток.

## Граница доказательств
Зелёная сборка, JVM и API30/35/36 не проверяют управление реальной игрой на физическом планшете. Возможные отдельные проблемы Шипучки, Гексона, Гошана и Карканоида остаются. Документ не заявляет исправление исходного пользовательского бага.
