## Перед обновлением

Не удаляйте установленное приложение и не очищайте его данные.
Подпись этого APK проверена, но совместимость с ключом телефона неизвестна.
Сертификат CI APK SHA-256:

`010a04cb0888a4627b095def584f131b5161cff81c4d74c1513cbb932bfafcde`

Уже установленный пакет можно найти командой:

```sh
adb shell pm list packages org.localpilot.android
adb shell pm path org.localpilot.android.dev
```

Если установлен `org.localpilot.android` без `.dev`, это другой пакет;
данные и профили автоматически в `.dev` не переносятся.
Для `.dev` скопируйте указанный `pm path` файл `base.apk` с телефона на ПК
и сравните вывод `apksigner verify --print-certs` для него и нового APK.
Сравнивается `Signer #1 certificate SHA-256 digest`, не SHA-256 самого APK.
Только при совпадении пакета и подписанта применимо обновление `adb install -r`.
При несовпадении нужен доступ к прежнему ключу подписи. Переподписание любым
новым или просто локальным debug-ключом совместимость не создаёт.

`Экспорт журнала` не является полной резервной копией профилей и обучающих баз.

## Физическая приёмка

Проверять на телефоне и планшете, записав модель, Android и размер экрана.

1. Мастер калибровки: выбор приложения, окна и ROI, подтверждение области;
   панель не пересекает ROI, угол и размер области соответствуют игре.
2. На распознанном устойчивом поле подтвердить один ход, затем пять подряд.
   Считать визуальные подтверждения, а не Android ACK. Зафиксировать профиль,
   число отправок и число подтверждённых изменений поля.
3. Нажать STOP: дальнейшие отправки не появляются; смена окна и поворот
   не возобновляют старую сессию. Для новых действий нужен актуальный контекст.
4. После разрешённого обновления убедиться в сохранности палитр, профилей
   и обучающих данных. Не удалять старую версию ради установки кандидата.
5. При паузе сохранить текстовую диагностику: причина, CAPTURE/READ/ACK,
   `CAPTURE_CALLBACK_TRACE`, состояние сессии. Не считать ACK доказательством хода.
