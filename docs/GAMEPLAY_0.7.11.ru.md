# LocalPilot 0.7.11 — прогноз движения машины и птенца

Машина и птенец получили отдельный контроллер ArcadeController с состоянием между кадрами. Изменения относятся к профилям Маркет Раш / Гошан, вперёд!; Ари, Карканоид и головоломки не объявлены универсально решёнными.

## Что изменилось

Машина оценивает скорость приближения автомобилей, время до столкновения и весь путь перестроения, включая автомобиль рядом. Планируются до двух последовательных переходов между полосами. Удержание стороны экрана длится100–180мс вместо фиксированного50мс; оценка руления уточняется по видимому смещению. Дополнительное выравнивание разрешается при признаках непрерывного руления, чтобы не отправлять лишнее переключение полосы в дискретной игре.

Птенец моделирует высоту и вертикальную скорость, оценивает гравитацию/силу прыжка и приближение препятствия. Поиск сравнивает несколько последовательностей прыжков; прогноз учитывает возраст кадра. Повторный подъём ограничивается, когда птица уже летит вверх к целевой высоте. Между раундами сохраняются измеренные параметры физики в памяти текущей сессии.

Распознавание: собственное стекло машины исключено из препятствий, цветные части автомобиля объединяются. Для птенца выбирается достижимый проход, одиночные сегменты препятствий учитываются, а полка на фоне не принимается за пол без непрерывной опоры ниже. Эти ошибки обнаружены в настоящих пользовательских записях.

Цикл управления: исходный интервал кадров60мс вместо120мс; это верхняя частота запроса, не обещание16FPS на телефоне. Ожидающий кадр заменяется новым; последний пригодный кадр для слежения сохраняется до500мс. Прогноз обновляется при ожидании ACK. Перед касанием проверяется фактический возраст кадра после записи журнала (до300мс). Журнал по-прежнему сохраняется синхронно, поэтому медленный накопитель может ограничивать скорость.

Android ACK и видимая реакция игры учитываются отдельно. На реакцию выделяется300мс у птенца и450мс у машины; повторное решение строится по свежей сцене. После трёх неподтверждённых действий ввод приостанавливается с сохранением захвата. «Старт» возобновляет проверку в том же окне. STOP/блокировка/смена окна по-прежнему прекращают ввод.

## Проверки

Результаты окончательных прогонов — VALIDATION.txt и docs/GAMEPLAY_EVIDENCE_0.7.11.txt. Разделены: реальные записи (проверка распознавания), моделируемые раунды по координатам (проверка планирования), полный цикл с синтетическими изображениями (проверка соединения компонентов), сборка и компиляция instrumentation.

Реальные видео: вручную отмечены активные интервалы TRAFFIC20..80 и FLAPPY7..57. После исправлений пригодны61/61 и51/51 активных кадров; до исправления одиночного сегмента и пола птенец терял10кадров. Это покрытие распознавания данных записей, а не точность на неизвестных играх или самостоятельное прохождение.

Физический Android здесь не подключён; API захвата/специальных возможностей и достижения в установленной игре не проверены. Модели физики и цветовые профили имеют ограничения. Хороший уровень автономной игры на телефоне остаётся критерием приёмки, который эти проверки целиком не закрывают.

## Измеренный результат

В полном цикле с изображениями (по четыре моделируемых сценария на режим) машина прошла34 ряда без столкновений вместо7 рядов/4 столкновений у прежней стратегии с той же обратной связью; результат одинаков для дискретного и непрерывного руления. Птенец прошёл19 препятствий с1 столкновением вместо6/3. Один сбой птенца остаётся; проверки не подтверждают хороший уровень в настоящей игре на телефоне.

В156 сценариях по координатам новый контроллер с обратной связью прошёл561 проход у птенца против315,1004 ряда машины против180,911 рядов с удержанием против118. Результаты суммарные по наборам, а не рекорды одного раунда. Полный цикл по пикселям проверяет соединение модулей отдельно от этих сценариев.

## Запуск

1. Установите APK обновлением поверх Dev-версии.
2. Откройте раунд, выберите окно и профиль игры на панели, нажмите Старт.
3. Подтвердите показ всего экрана. После распознанного результата нажмите повтор в самой игре; захват и область сохранятся, пока доступно то же окно.

Подпись/данные обновления сохраняются; исходники, web-примеры и резервные копии не удаляются. Backup проекта: /workspace/localpilot-backups/android-before-predictive-0711.tar.gz.
