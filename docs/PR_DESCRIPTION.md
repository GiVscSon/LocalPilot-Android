Add Android0.4.0-dev/code8 with four original deterministic arcade environments and native CPU Double DQN training. The APK needs no Python, server, GPU, or Internet permission. The simulation and learning core has no Android dependencies; Gymnasium wrappers call the same Java implementation through JPype, and the PC CLI can resume the same checkpoint.

The training screen provides genre selection, training, pause/Stop, frozen-policy playback, paired50-episode evaluation, and checkpoint export. Checkpoints preserve online/target weights, Adam state, replay, RNG and environment state, validate SHA256/configuration/bounds, and recover a checked backup without discarding a corrupt original. Backgrounding the Activity pauses and saves.

Selected supported games now discover their board automatically with autoplay enabled by default and no repeated consent dialog or artificial action/time cap. Binding epochs, fresh frames, single-use tickets, profile verification and STOP remain enforced. The compact160×48dp panel uses a55%-opaque background. Audit rotates eight bounded v1 segments and exports ZIP; previous audit files are preserved. Full experience storage disables collection while allowing gameplay to continue.

Validation: see VALIDATION.txt for final JVM, native build/lint, Gymnasium, numerical gradient, exact checkpoint-continuation and training/evaluation results. Functional learning and an improved game policy are reported separately. Existing software-emulator failure prevents device acceptance; the native UI runner is compiled but unrun. New Doodle Jump/third-party arcade vision/control profiles are not implemented. No claim of physical-phone training speed, thermal behavior, or universal gameplay.
